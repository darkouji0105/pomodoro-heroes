## 3. 形の案（⚠ 実装する回が裁いてよい。⚠ ただし `TK-n` は変えない）

### 3-1. 状態（`GameStateKeys` に足す）

```
TASKS:      [{task_id, title, memo, due, color, tags: [String], pomodoro_count, created_at, done_at}]
            ⚠ 配列の並び＝表示の順（TK-7 の「並べる順」）。⚠ done_at が 0 ならまだ
TASK_LOG:   [{task_id, title, color, tags, pomodoro_count, created_at, done_at}]
            ⚠ 終わったタスクの記録（TK-6・TK-9）。⚠ 朝4:00 に TASKS から移す
```

- ⚠ **タスクの文は人間が書いたもの＝マスターデータではない。** ⚠ `CLAUDE.md` 4番（状態にマスターを複製しない）には当たらない。⚠ 記録へ題を写すのもよい
- ⚠ `due` は `GameDate.get_game_date_string()` と同じ形の文字列（`""` なら期限なし）。⚠ 「今日」の判定は `GameDate`（朝4:00 区切り）
- ⚠ `color` は色の番号（`int`）。⚠ ⚠ `MasterDataLoader` を通らないが、⚠ JSON のセーブから戻ると `float` で来る＝**`int()` で包む**（`CLAUDE.md` 3番）
- ⚠ 書き換えの口は `GameManager` に集める（`add_task()` / `update_task()` / `move_task()` / `set_task_done()` / `add_task_pomodoro()` / `roll_over_done_tasks()` のような形）。⚠ 画面から `TASKS` を直に触らない
- ⚠ シグナルを1本足す（`tasks_changed`）。⚠ 拠点の紙とタスクの画面はこれで描き直す（⚠ `CLAUDE.md` 5番＝`remove_child()` してから `queue_free()`）
- ⚠ 朝4:00 の移しは、⚠ いまの `reset_daily_pomodoro_state_if_needed()` と同じ時に呼ぶ（⚠ 拠点を開いたとき・ポモドーロを開いたとき）

### 3-2. 画面と部品

| もの | 置き場（⚠ 新しいフォルダは作らない） | 中身 |
|---|---|---|
| 拠点の紙 | `scenes/base/`（⚠ 1画面だけ＝`AGENTS.md` 置き場のルール） | まだのタスクを上から数件・色の印・期限の判（`TK-3` `TK-13`）。⚠ 押すとタスクの画面へ |
| タスクの画面 | `scenes/base/task_screen.tscn`（⚠ 新しい `.tscn` が1つ増える。⚠ 人間は「い」で承知） | 一覧・足す・チェック・並べ替え・詳しく（メモ・期限・色・タグ）・タグで絞る。⚠ 開くのは `SceneManager` 経由 |
| 選ぶ窓 | `scenes/pomodoro/`（⚠ ポモドーロ画面だけで使うなら） | まだのタスクの一覧から選ぶ。⚠ その場で足すこともできる |
| 記録のタブ | `records_screen.gd` に4つ目（`TK-8`） | 終えた日・題・🍅の数。⚠ 上限なし（`TK-9`）なので、⚠ 行が多いときに重くならないか見る |

### 3-3. 🍅を数える時

⚠⚠ **未決（人間に聞く）。** ⚠ 設計役のおすすめは「**集中のタイマーが0になった時**」。

- ⚠ いまの「集中の分」は振り返りを確定したときだけ加算される（`pomodoro.gd` `_on_reflection_completed()` の `if not skipped`）
- ⚠ `TK-4` で「振り返りでは聞かない」と決まったので、⚠ 🍅を振り返りに縛る理由が無い
- ⚠ ただし「振り返りを逃したら0分」とずれる（⚠ 集中の分は0、🍅は1）。⚠ それをよしとするかは人間が決める

### 3-4. 数値の置き場

⚠ 拠点の紙に出す件数・色の数は**つまみ**＝`AGENTS.md` 数値管理ルールで Config に置く。
⚠ 案：`PomodoroConfig` に `@export` を足す（⚠ 新しい Config を作ると `balance.tscn` に配線が要る）。
⚠ **色そのもの**は Theme 側（`tools/theme_builder.gd`）。⚠ シーンに色を書かない。
