## 7. 宝箱

⚠ **積む口は `grant_chest()` の1本だけ**（`game_manager.gd:908`）。⚠ **戦闘もポモドーロもここを通る。**

| | 経路 |
|---|---|
| 入口（戦闘） | `apply_battle_rewards()` → `_grant_stage_chest()` → `grant_chest()` |
| 入口（ポモドーロ） | ⚠ **その日の累計集中分がしきい値に達すると加護の宝箱**（`claim_pending_chests()` ／ `protection_*.tres` の `ChestScheduleEntry`） |
| 出口 | `open_chest()` → `add_gold` / `add_gems` / `add_material` / `add_to_inventory` |

⚠ **中身は積むときに振って個体に焼き込む。⚠ 開けるときには振らない。**
⚠ **抽選のハズレ枠（`weight: 70` の空欄）を引くと `_is_rewards_empty()` が真になり、⚠ 宝箱そのものを積まない＝「3割の周でしか出ない」の正体。**
⚠ **研究の `chest_draw_bonus` は `_roll_chest_draw()` の `rolls` にだけ乗る。⚠ `weight` には乗らない。**

⚠ **この節は `PLAN_SCENARIO_MAP.md` §4 で作り替えが決まっている**（⚠ **ハズレ枠の廃止・`chest_id` をフロア×レアリティへ**）。⚠ **作り替えたらこの節を更新すること。**

## 8. ⚠ 触るときの注意

- ⚠ **入口か出口を1つ足したら、⚠ `debug_boot._economy_sources()` と `_economy_sinks()` の**両方**を見る。⚠ 対になっている**
- ⚠ **素材を1件でも動かしたら `scenario=economy` を回し直し、⚠ 前後の数字を EXEC に並べる**
- ⚠ **`_roll_weighted_table()` にボーナスを足さない。⚠ 抽選の本体はここ1本だけ**
- ⚠ **`grant_chest()` / `add_to_inventory()` を2本目にしない**
- ⚠ **`ChestScheduleEntry.chest_type` を改名すると `protection_*.tres` の7件が黙って空になる**
- ⚠ **リリース後に素材ID・`chest_id`・レシピID・ノードIDを改名しない**
