### 等級付き素材について

**プレイヤーから見れば1種類、データとしては`item_id`が3つ。** アイテムは`item_id`と個数でしか持てないため。`ja.csv`に3行、ドロップに3箇所要る。

**下位→上位の変換レシピは既存の`convert_con_to_tra`のコピーで済む。** コードは1行も変わらない。**レートは1未満を保つ**（既存レシピと同じルール）。

> **これが無いと低いステージが腐る。** 上位素材が高ステージでしか落ちないと、序盤のステージは価値がゼロになる。変換があれば「時間をかければ下位素材でも上位に届く」になり、ショップ／作業場の「今すぐか、待つか」がここにも乗る。

## 3. 等級（鍛冶）

### 3-1. 基本

- [x] **等級は全部で10段階**
- [x] 上げるには`forging_material`と時間（作業場の鍛冶）
- [x] **失敗しない。** 素材と時間を払えば必ず上がる
- [x] **等級による本体のステータス係数は「加算」にする。** 等級ごとに基礎値の一定割合を足す
- [ ] 各等級の必要素材量と所要時間
- [ ] 鍛冶を作業場のレシピとして扱うか、専用の画面／タブにするか

> **係数を乗算にするとインフレする。** 等級ごとに×1.2なら10段階で6.2倍。加算なら3倍で止まる。**`def`と`haste`が除算で逓減する設計なので、加算の軸だけが線形に伸びる。そこを乗算で重ねない。**

> **本体の係数は必ず効かせる。** 宝石を持っていないプレイヤーが等級を上げたとき、係数が無いと素材と時間を払って何も変わらない。**枠は上乗せであって、鍛冶の見返りの本体にしない。**

> **既存の作業場は「レシピを選んでキューに入れる」形。** 鍛冶は「どの個体を強化するか」を選ぶ必要があり、レシピの形に乗らない。**着手時に`workshop_screen.gd`を見てから決める。**

### 3-2. 等級による解放

- [x] **5部位すべてが同じ形。等級5で1枠、等級10でもう1枠**
- [x] 武器・アクセサリーの枠に刺さるのは**ルーン**（スキルに作用する）
- [x] 頭・上半身・下半身の枠に刺さるのは**宝石**（ステータスを上げる）
- [x] **枠には等級（`tier`）を持たせる。倍率を持たせない**
- [x] **下位`tier`の部品も上位の枠に刺さる**
- [ ] 等級10で開く枠を1つにするか2つにするか

> **倍率にすると、装備の等級係数と枠の倍率が掛け算で重なる。** バランスの計算道具で最大値を出すのに全組み合わせを回すことになる。**枠に等級を持たせる形なら、強い部品が刺さるようになるだけ。判定は1行。**

> **下位が刺さらないと、等級10まで上げた瞬間に枠が空のままになる。** 上げたのに何も起きないのは、この設計の原則にいちばん直接ぶつかる。

> **枠を減らす変更をしたときは、あふれた部品を加算せず、配列からも消さない。** `push_warning`を出して残す（`items.json`からIDが消えた装備と同じ扱い）。**黙って倉庫に返すと「無くなった」に見える。**

### 実装コスト

**`character_config.tres`の`stat_growth_formula`を`"base"`に変えるだけで、ステータス成長が止まる。**

```
現在: "base + growth * (level - 1)"
変更: "base"
```

`_recalc_stats()`が毎回レベルから計算し直す作りのため、**既存セーブも次の起動で素の値に戻る。`.gd`は1行も触らない。戻すのも1行。**

`characters.json`の`growth_per_level`は読まれなくなるだけで、消さなくてよい。

> **代償：序盤に伸びる手段が無くなる。** レベル1の剣士（`atk` 18）が次に強くなるのは、作業場で30分待って木の剣（+3）を作ったとき。**宝箱から低級装備を出す（2-3）ことで塞ぐ。**

> **育成画面の作り替えが要る。** いまはレベルを上げるとステータスが上がる画面。パッシブの取得状況と次の節目が見える形にする。**`training_screen.gd`の差し替えは装備の第2弾より大きくなる可能性がある。**

### ライフスティールとHP自動回復

**ステータスの軸としては入れない**（理由は`PLAN_STATS_AND_FORMULAS.md`）。**キャラのパッシブとして持つ候補として残す。**

- [ ] 剣士のパッシブにライフスティール、僧侶に`hp_regen`を置くか
- [ ] その場合、ステータスではない効果を戦闘に流す経路が要る（パッシブ第1弾を「ステータス加算だけ」にすれば先送りできる）

> **捨てたのではなく、置き場所を変えた。** 全員が持てる軸にすると「誰でも刺せる」になるが、パッシブならそのキャラの性格になる。

## 10. 実装の順番

```

   ＋ 装備の第2弾（5部位・equipment_instances・鍛冶）
C. パッシブ（一本道・5レベルごと）              ← Bのステータス軸に依存する
D. 宝箱に低級装備                             ← 独立。いつでもできる
E. 宝石（tier・ロール・振り直し）
F. パーティ選択
G. ルーン
H. 投射物
I. SDキャラとアニメーション（専用の会話）
—— この後にバランス調整（balance_report.py で逆算）
```

**BとCの順番は固定。** 「レベル20でクリティカル率+10%」を書くには`crit_rate`が先に要る。

**セーブ構造を触るのはBの1回だけ。** スキルポイントを作らないと決めたことで、2回目が消えた。

**バランス調整は最後。** 素材の種類・ステータスの軸・等級の構造が全部変わるため、いま数値を詰めても作り直しになる。**道具（`balance_report.py`）は先にあるので、構造が固まった時点で逆算できる。**
