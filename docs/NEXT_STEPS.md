### ⚠ 敵が自分に状態を掛ける前に殺すと、検証が「無音で通る」

⚠ **2件入れると、片方の効果が乗った数字を「素の値」として比べてしまう**（介入点で実際に踏んだ）。

### ⚠ 静的な突き合わせは実機の代わりにならない

⚠ **段階4で、ロード時検証を Python で真似て「OK」と言ったが実機では10件の赤が出た。⚠ ヘッドレスが使える。真似ずに走らせること。**

### ⚠ Windows の bash で `cat >>` すると追記分が CRLF になる

元が LF の JSON に混ざって壊れる。**JSON に追記したら改行コードを確かめる。**
