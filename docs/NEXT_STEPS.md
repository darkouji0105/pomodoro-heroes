### 通常攻撃のデータ化（`03a0d8e`）

`characters.json` / `enemies.json` の各エントリに **`basic_attack`（9件）**。形は skills の1件と同じ `{ "effects": [ ... ] }`。**`_compute_damage()` は廃止**され、`_fire_basic_attack()` が新層を通す。**挙動不変で通った。**

### 投射物（`3fb91b9` ＋ `9b202ff`）

```
SkillRuntime      効果を「着弾待ち」で積み、矢を1本頼む（シグナル）
   ↓ projectile_requested        ⚠ この層はノードを触らない（契約）
BattleController  演出シーンを出す（データとビューが出会う唯一の場所・PLAN 7-1）
   ↓ setup()

   ↓ on_projectile_hit → notify_event(cast_id, "hit")
SkillRuntime      待っていた効果を発火（経路は _fire() の1本のまま）
```

⚠ **着弾までの遅れで、倒す順番と過剰攻撃が既に変わっている。** 弾速は `Balance.adventure.projectile_speed_px_sec`（既定 1200）／`magic_speed_px_sec`（既定 800）。

## 1. このタスク：**9件の通常攻撃に個性を入れる**

**器も経路も演出も揃った。⚠ 数字が変わるのはここから。**

いま9件は**全部同じ形**（`multiplier: 1.0` の単発ダメージ）で、違うのは `attack_type` と `delivery` だけ。**`effects[]` に何でも書けるのに、1つも使っていない。**

### 何が書けるようになっているか（**全部実装済み・実機で通っている**）

| 書けるもの | 例 |
|---|---|
| **複数の効果** | 殴って `dot` を付ける |
| **`trigger: "delay:N"`** | 2連撃 |
| **`trigger: "event:hit"`** | 着弾でダメージ（**飛ぶものは既にこれ**） |
| **`scale_from` の合成** | `atk` ＋ `def` を参照する重い一撃 |
| **`attack_type: "true"`** | 防御を無視する |
| **`buff` / `dot`** | 殴るたびに自分を強化・毒を盛る |
| **`heal`（`target: self`）** | 吸血する通常攻撃 |

⚠ **書けないもの**：条件（HPが低いときだけ）・購読（反撃されたら）。**どちらも段階3の後半。**

## 2. 着手前に人間が決めること

### 2-1. ⚠ **どこまで変えるか**（バランスに直結する）

⚠ **通常攻撃はスキルと違って「毎秒何度も出る」。** 倍率を 1.0 から動かすと、**戦闘時間が全部変わる。**

| 案 | やり方 |
|---|---|
| **A（推奨）** | **味方3人だけ個性を入れる。敵3体は `multiplier: 1.0` のまま** … 敵を触ると全ステージの難易度が動く |
| B | 敵も含めて9件とも書く | 
| C | 味方3人＋ボスだけ | 

### 2-2. ⚠ **検証用キャラ3体はどうするか**

いま `atk 1` で殴っている。⚠ **通常攻撃を凝らせると、検証中に敵が死んでウェーブが進む。** **`multiplier: 1.0` のまま据え置くのを薦める。**

### 2-3. 3人にどんな個性を持たせるか

⚠ **`GAME_DESIGN.md` にキャラの役割が書いてあるなら、そちらが正。** 無ければここで決める。私の案：

| キャラ | 案 | 使う仕組み |
|---|---|---|
| 剣士（`melee`・射程60） | **2連撃**（0.2秒差・各 0.6倍） | `trigger: "delay:0.2"` |
| 弓兵（`projectile`・射程300） | **距離が遠いほど強い**（`atk` ＋ `distance`） | `scale_from` の合成 |
| 僧侶（`magic`・射程250） | **殴ると自分が少し回復**（吸命） | `heal` ＋ `target: self` |

⚠ **どれも「合計ダメージが今と同じ」になるよう倍率を決めること。** 個性を入れる回であって、強くする回ではない。

## 3. ⚠ 事故りやすい箇所

### 3-1. ⚠ **多段の2発目には矢が出ない**（既知の穴）

**投射物は `cast()` の瞬間に、送り方1つにつき1本だけ出る。** `trigger: "delay:N"` の2発目は**矢なしでダメージだけ出る。**

⚠ **剣士は `melee` なので影響しない**（案どおりなら）。**弓兵に2連撃を書くと、2本目の矢が見えないまま2発目が当たる。**

### 3-2. ⚠ **通常攻撃に効果を足すと、待ち行列に積まれる数が増える**

`delay` を書くと、攻撃間隔ごとに要素が1つ増えて N 秒待つ。⚠ **`delay` を攻撃間隔より長くしないこと。** 前の攻撃の2発目が出る前に次の攻撃が始まり、行列が伸び続ける。

### 3-3. ⚠ **`buff` を書くと `stack` が要る**

`independent` にすると**殴るたびに無限に積む**（上限が未実装・宿題4番）。**通常攻撃に書くなら `refresh` にすること。**

### 3-4. ⚠ **`dot` を書くと発火が敵の数だけ走る**

`interval_sec` を短くしすぎないこと。

### 3-5. ⚠ **F3 パネルの `dmg` は1発目しか出さない**

`_format_damage_to_target()` は `BattleFormula.damage()` を1回呼ぶだけ。**多段や吸血を書くと、パネルの数字と実際の合計が合わなくなる。** これは**正常**（パネルは非会心の1発の目安）。
