## §2. ⚠⚠ いまの装飾（**ここが本題**）

### §2-1. 人間が実機で言ったこと

> ⚠ **「そもそも装飾をつけれない」**
> ⚠ **「どこからつけるかわからない」**

### §2-2. 刺すまでの道（**いまの実装**）

```
装備画面を開く
  → 部位の行の [選ぶ]（または装備マスを押す）
  → その部位に装備を着ける
  → ⚠ その装備を 等級3 まで [鍛える]（2回）      ← ここで初めて枠が現れる
  → 枠のマス（[宝][·]）が部位の行の下に出る
  → 枠のマスを押す → 吹き出し「宝石枠 ／（空き）／ [刺す]」
  → [刺す] を押す → 下段が「刺せる装飾（枠 1）」に変わる
  → 下段の一覧から装飾を選ぶ → 刺さる
```

### §2-3. ⚠⚠ 3つの「無音の門」（**どれか1つ欠けると、画面に装飾の話が一文字も出ません**）

| 門 | 条件 | いま画面が言うこと |
|---|---|---|
| **1** | **`floor_3`（3面）をクリアしている** | ⚠ **何も言わない**（⚠ 枠の行ごと消える） |
| **2** | ⚠⚠ **その装備が 等級3 以上**（⚠ 枠が開く等級は **3,4,5,5,6,7,8,9** の8枠） | ⚠ **何も言わない**（⚠ 開いていない枠は出さない決定） |
| **3** | **装飾を倉庫に持っている** | ⚠ 一覧が空になるだけ |

⚠⚠ **「この枠はまだ開いていない」という文言は用意されていますが、⚠ 閉じた枠を出さないので絶対に表示されません。**
⚠ ＝**プレイヤーには「装飾なんて無い」ように見えます。**

⚠ 装飾の種類は4つ：**宝石枠 ／ 護符枠 ／ 紋章枠 ／ ルーン枠**（＋ どれでも刺せる**ワイルド枠**）。
⚠ 頭・上半身・下半身は3番目の枠がワイルド、⚠ アクセサリーは3番目がルーン枠。

### §2-4. 外すと壊れる

⚠ **装飾を外すと壊れて素材に戻ります**（⚠ 取り返しがつかない）。
⚠ いまは吹き出しの **赤い [外す]** → 確認の窓「◯◯ を外すと壊れます。素材に戻りますか？」。

### §2-5. いまの枠の見た目（**2026-09-22 に入れたばかり**）

- ⚠ 部位の行の下に**マスが横1列**（⚠ 開いている枠だけ）
- ⚠ **空き** … 種類の線画を薄く。⚠ **枠線＝そこに刺さる種類の色**
- ⚠ **刺さっている** … 刺したものの線画を明るく。⚠ **枠線＝その等級の色**
- ⚠ **ワイルド枠の空きは虹色の枠線**
- ⚠ 押すと吹き出し（⚠ 幅236）：「宝石枠 ／ 攻撃の宝石① 攻撃 +4 ／ **[外す]（赤）** ／（移動量のボタン）」

## §3. いまの「鍛える」

- ⚠ **部位の行のボタン1つだけ**（`鍛える(鍛冶の塊 20)`）。⚠ 押すと等級が1つ上がる
- ⚠ **等級は最大10**。⚠ 素材は等級で段が変わる（⚠ 1〜3は①、4〜6は②…）
- ⚠ 性能は **等級で伸びる**（⚠ 素の値 ＋ 等級1つごとに一定の割合）
- ⚠⚠ **画面はどこにも「鍛えると装飾の枠が開く」と書いていません**
- ⚠ 「次の等級の性能」を**押す前に見せる**のは 2026-09-14 に決まっています。
  ⚠ **値を引く口は在りますが、⚠ 画面はまだ使っていません**（⚠ 出ているのは今の等級の加算だけ）

## §5. 決めてほしいこと（**いまは決まっていません。⚠ 案を出してください**）

### §5-1. ⚠⚠ 持っている装飾を、どこから刺すのか（**最重要**）

⚠ いまは「**装備 → 部位 → 鍛える → 枠を押す → 刺す → 下段から選ぶ**」の6手。
⚠ 人間は **「どこからつけるかわからない」**と言っています。⚠ 例えば：

- ⚠ **倉庫の装飾をつまんで枠へ落とす**（⚠ **装備マスへのドラッグは既に動いています**＝同じ手が使えます。
  ⚠ Godot の標準では OS の別窓どうしで落としが渡らないので、⚠ 自前の受けを作ってあります）
- ⚠ **装飾のほうから「どの装備に刺すか」を選ぶ**（⚠ 逆向きの導線）
- ⚠ **枠を押したら、⚠ 吹き出しの中に刺せる装飾を並べる**（⚠ 下段へ飛ばさない）
- ⚠ **装飾の専用画面を作る**（⚠ ただし画面を増やすのは重い。⚠ 人間の裁きが要る）

⚠ **どれでもよいので、⚠ 「6手を何手にしたか」を案ごとに書いてください。**

### §5-2. 「まだ刺せない」をどう伝えるか

⚠ **閉じた枠を見せるか／見せないか。** ⚠ 2026-09-08 に人間は「**未開放は表示しない**」と決めましたが、
⚠ その結果が §2-3 の無音です。⚠ **覆す案を出してよい**（⚠ 出すなら「何を見せるか」も書いてください）。

### §5-3. 部位の行の形

⚠ いまは **文字1行＋ボタン3つ × 5部位**。⚠ 装備マスと二重になっています
（⚠ 上の5マスと下の5行が同じことを言っている）。⚠ どちらかに寄せますか。

### §5-4. 「鍛える」をどこに置くか

⚠ いまは部位の行のボタン。⚠ 装飾の枠と同じ場所にあるので、⚠ 「鍛える → 枠が開く」がつながるかもしれません。

### §5-5. 左のステータス10軸

⚠ いまは10行ずっと出ています。⚠ 装備を選んでいるあいだ「**着けたらこうなる**」を出すかどうか。
