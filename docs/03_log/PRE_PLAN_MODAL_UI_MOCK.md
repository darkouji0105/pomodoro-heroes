## 1. いまの窓（`ModalDialog`）

全画面が**1つの部品**を共有しています。`Modal.notify()`（知らせる）と `Modal.confirm()`（はい／いいえ）の2通りです。

いまの形（上から）：

1. **暗幕**（画面全体・黒 60%。⚠ 後ろは押せない）
2. **窓**（真ん中・最小幅 400・縁は真鍮）
3. **題の帯**（あるときだけ出る。中央ぞろえ）
4. **中身**（⚠ 差し込まれた Control が入ることがある。例：宝箱の開封結果のマス目）
5. **本文**（中央ぞろえ・折り返しあり）
6. **ボタンの行**（知らせる＝「閉じる」1つ ／ 確認＝「いいえ」「はい」の2つ）

**積み方**：窓が出ているあいだに次の窓が来たら、**順番に並べて1つずつ出します**（同時に2枚出しません）。

## 2. どこで出るか（全部で14か所）

| 画面 | 何を出すか | 種類 |
|---|---|---|
| 拠点 | ポモドーロの受け取り報告（ポーション n 個・宝箱 n 個） | 知らせる |
| 拠点 | セーブした／セーブに失敗した | 知らせる |
| 拠点 | タイトルへ戻る？ | 確認 |
| 倉庫 | この品を捨てる？ | 確認 |
| 倉庫（宝箱） | 開封の結果（⚠ 絵と名前がレアリティの色・マス目つき） | 知らせる＋中身 |
| 装備 | 装飾を壊す？ | 確認 |
| ポモドーロ | 作業をやめる？ | 確認 |
| タイトル | セーブを消す？ ／ 消した ／ 消せなかった ／ 読み込めなかった | 確認・知らせる |
| 難ダンジョン | 通路のできごと（罠・拾いもの・宝箱。⚠ 題に絵文字・HP の前 → 後・品のマス目） | 知らせる＋中身 |
| 難ダンジョン | 鞄に入れた（⚠ 入った／入らず失われた のマス目） | 知らせる＋中身 |

## 3. 描いてほしいもの

1. **知らせる窓（文だけ）**：例「セーブしました」
2. **確認の窓**：例「タイトルへ戻りますか？」＋「いいえ」「はい」
   - ⚠ **取り返しのつかない確認**（セーブを消す・品を捨てる・装飾を壊す）は、**はい**を赤にするか、別の見せ方にするかを提案してください
3. **中身つきの窓**：宝箱の開封結果（アイコン＋名前＋個数のマス目が6件くらい）
4. **長い本文の窓**：3〜4行になるとき（⚠ 折り返しと最大幅）
5. **窓が続けて出るとき**：2枚目が出るまでのつなぎ（⚠ そのまま差し替えるのか、⚠ 間を置くのか）

## 4. 決めてほしいこと（いまは決まっていません）

- **題の帯は常に出すか**（いまは「題を渡したときだけ」出ていて、⚠ ほとんどの窓に題がありません）
- **閉じるボタンの位置**（⚠ 拾いものの窓は人間の指示で**下**にしました。⚠ ほかの窓もそろえるか）
- **窓の幅**（いまは最小400。⚠ 中身つきの窓はもっと広い）
- **ボタンの並び**（⚠ 「いいえ・はい」の順／ 右ぞろえか中央ぞろえか）
- **暗幕の濃さ**（いまは黒60%。⚠ 難ダンジョンの拾いものは72%）
- **出入りの演出**（いまは無し。⚠ 付けるなら短く）

## 5. 変えないこと

- **窓の縁と題の帯は全部のモーダルに付ける**（人間の決定・2026-09-18）
- 色・ボタンの5階層・絵文字の制限（⚠ 依頼書 §2 と同じ）
- **後ろは押せない**（⚠ 暗幕が受け止める）
- 数値（個数・価格）は**仮の値**。モックで決めない
