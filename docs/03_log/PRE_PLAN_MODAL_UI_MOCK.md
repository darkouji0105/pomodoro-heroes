## §1. いまの窓（**これを作り直します**）

全画面が**1つの部品**を共有しています。`notify()`（知らせる）と `confirm()`（はい／いいえ）の2通り。

いまの形（上から）：

1. **暗幕**（画面全体・黒60%。⚠ 後ろは押せない）
2. **窓**（真ん中・最小幅 **400**・縁は `#4a3d36`）
   - ⚠ **2026-09-21 訂正**：⚠ ここは前の版で「縁は真鍮」と書いていたが**誤り**。
     ⚠ 真鍮（`#a8791f`）を使うのは**題の帯の下の線**。⚠ §0 が正（⚠ モック側が見つけた）
3. **題の帯**（⚠ **題を渡したときだけ**出る。中央ぞろえ）
4. **中身**（⚠ 差し込まれた要素が入ることがある。例：宝箱の開封結果のマス目）
5. **本文**（中央ぞろえ・折り返しあり）
6. **ボタンの行**（知らせる＝「閉じる」1つ ／ 確認＝「いいえ」「はい」の2つ）

**積み方**：窓が出ているあいだに次の窓が来たら、**順番に並べて1つずつ**出します（⚠ 同時に2枚出しません）。

## §3. 描いてほしいもの（**5枚**）

1. **知らせる窓（文だけ）** … 例「セーブしました」
2. **確認の窓** … 例「タイトルへ戻りますか？」＋「いいえ」「はい」
   - ⚠⚠ **取り返しのつかない確認**（⚠ セーブを消す・品を捨てる・装飾を壊す）は、
     ⚠ **「はい」を赤にするか、別の見せ方にするかを提案してください**
3. **中身つきの窓** … 宝箱の開封結果（⚠ 絵＋名前＋個数のマス目が6件くらい）
4. **長い本文の窓** … 3〜4行になるとき（⚠ 折り返しと最大幅）
5. **窓が続けて出るとき** … 2枚目が出るまでのつなぎ（⚠ そのまま差し替えるのか・⚠ 間を置くのか）
