難ダンジョン モック v2（2026-09-19 / 3枚目）

選ばれた部品で全画面を組み直しました。マス＝真鍮の札、線＝手描きの道、＋たいまつの明かり。色・ボタン階層・絵文字の制限はそのままです。

真鍮の札は25層並べると騒がしくなるので、未見のマスだけ鋲を外して静かにしてあります（明かりの中に入ると鋲が点く＝進むほど地図が立ち上がる）。手描きの線は揺れを ±6px に抑え、罠だけ折れ線にしています。

実寸 1280 x 720。マス目はホバーで詳細、鞄のマスはクリックで「できること」。

§0 たいまつの明かり

3つ重ねています。①いまいるマスを中心にした光（金の薄い放射・5.5秒でゆっくり揺れる。動きを減らす設定では止まる）、②届かない層を覆う暗さ（黒の透過だけ。等級が上がると境目が上へ動く）、③未見の札は鋲が無い。等級1/2/3 を並べたのが下の画面です。等級を上げると「暗さの壁が上がる」のが見えるので、商人でたいまつを買う理由が画面から分かります。

§1 マップ（a）入口にいる

列は画面の真ん中（要望37）。左端に層の目盛り、5層ごとに区画の切れ目。区画の入口なので3択、いまいるマスから出る線は太くしています。

§2 マップ（b）区画の中

通ったマスは鋲が沈み、明かりの外は暗く覆われます。1層先に罠の通路（折れ線＋💥）。

§3 マップ（c）ボスを倒した直後

ボスの札だけ一回り大きくして、ふつうのマスと格を分けています。倒したあとは明かりが部屋いっぱいに広がる（暗さの覆いを外す）。

§4 マップ（d）1人が脱落・鞄が満杯

脱落は赤。鞄が満杯のときはヘッダの数字も赤。鞄のマスを押したところ（脱落中のキャラのボタンは赤）。

§5 マップ（e）区画の中に分岐（要望38）

区画の入口の3択は太い線、区画の中の分岐は細い線。中の分岐は最後に合流させています。

§6 拾いもの（a）3品・鞄に余裕あり

後ろのマップは暗く透けます。窓の縁は真鍮、題の帯つき。シナリオでも同じ窓です。

§7 拾いもの（b）鞄が満杯

赤い帯で理由、「入るだけ全部入れる」は押せない。入れ替えは下の鞄から捨てる。

§8 窓を閉じたときの自動収納（要望40）

A案メッセージ行に1行。B案OKだけの小窓で「入った／失われた」をマス目で。失うものがゼロならA案だけ、あるときはB案、の混ぜ方を推します。

§9 レリック選択（選ぶまで出られない）

戻るは無し。候補は札ではなくマス目（倉庫・鞄・商人と同じ部品）。

§10 ボスの間の商人

鞄に入る品はマス目、入らない品は行。たいまつの行に「いま 1層先 → 2層先」と変化を出しています。

§11 通路のできごと（OKだけ）

§12 つけているレリック（要望46）

v1 の B案（ヘッダ右端の🔮マス目）を全画面に入れてあります。付けた人はマスの左下に印、ホバーで効果。
