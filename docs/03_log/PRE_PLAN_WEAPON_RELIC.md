## 2. 1プレイの単位

**決まり**

- ポモドーロの25分は**仕事の時間**で、遊ぶのは休憩（5分／長い休憩15〜30分）。
  よって **「1プレイ＝1ラン」ではない。「1プレイ＝休憩1回」**。
- 1ラン＝3階×25層＝75層は、1層 t 分として 75t 分。**休憩1回には収まらない。**
- **区画（5層）を、休憩1回で区切れる単位にする。** そこを必ず中断・再開できる点にする。
- 中断したランがそのまま残るなら、75層のままでよい。

**未決**

- 1層の平均時間 t（テストプレイで実測）。
- ランの中断・再開が今どこまでできるか（未確認）。

## 3. 持ち物：拠点の倉庫をやめる

**決まり**

- **拠点の500マスの倉庫をやめる。** マス目・ページ送り・枠を買う・並べ替え・容量の概念を拠点から外す。
- **拠点側は「持ち物の画面」に置き換える。** 見出しは **装備／装飾／素材／図鑑** の4つ。
  - 装備 … 持っている個体の一覧（部位・等級・装飾の数・着けている人）
  - 装飾 … 名前つきの数字。段階を上げる・重ねる・壊す
  - 素材 … 数と使い道。見るだけ
  - 図鑑 … **遺物の置き場**（§7）
- 品の操作は「説明の窓」1つに集める（`DECISIONS.md` `BS-16` のまま）。
- 装備画面は「このキャラに着ける・刺す・鍛える」、持ち物の画面は「持っているもの全部を扱う」。

**理由（3つ）**

1. **原則Aとぶつかる。** 倉庫を有限にした代償として6本の口に「入らないなら止める」が入り、
   宝箱が開けられない・ショップで買えない・ポモドーロの報酬が押し戻される、が起きている。
2. **上限として働いていない。** 実測315マスに対して500マスが最初から全部開いている。
3. **タルコフの「煩雑さは持ち込まない」に反する。** 重ねない1マス1個は拠点に整理の手間を持ち込んでいる。

**拠点側の「犠牲」はどこで担保するか**

- 素材の配分（どの装備の等級に注ぐか）
- 装飾は外すと壊れる
- ジャンル共有の武器を**誰に持たせるか**（§4）
- 等級5以上は失敗する（素材を失う）。確定させたければトークンを使う（§6）

**未決**

- **画面は増えない**（§0-2 D）。いまの倉庫画面を4つの見出しに作り替える形。
- 持ち物の画面の入口（ギルドのカードか、拠点の下段か）。
- `slot_position` / `INVENTORY_ORDER`（マスの並び）の後始末。

## 4. 武器

**決まり**

- **ジャンル共有。** キャラ専用にはしない。ジャンルが「誰が持てるか」を決める。
- **ジャンルは武器の形で切る**（剣・杖・弓 など）。
- **縦の並び（木・鉄・鋼）は廃止。** 強さの差は**等級だけ**。同じ等級なら総合力はほぼ同じで、上位互換を作らない。
- **各ジャンルに型を置く。型の名前は全ジャンル共通。** まずは3つ：

| 型 | 伸ばす軸 | 下げる軸 | 備考 |
|---|---|---|---|
| **タンク型** | **HP** | 攻撃 | **防御は持たない**（防御は防具の担当） |
| **速度型** | 攻撃速度・会心率 | 1発の重さ（攻撃） | |
| **スキル型** | 魔力・CD短縮 | 素の攻撃 | 手動で触る回数が増える型 |

- **防御は防具の担当。** 武器は物理防御・魔法防御を持たない。
- 型は「伸ばす軸」と「下げる軸」を必ず対にする（同じ等級での総合力を揃えるため）。

**数**

- ジャンル3 × 型3 ＝ 武器9種。装備は現在の11種 → 17種になる。
- 最初は1ジャンル2〜3本に抑えて、遊んでから足す。

**未決**

- ジャンルの数と名前、型の数（まずは3つ）。
- 攻撃1は防御何点ぶんか、というレート（総合力を揃える約束を数字で持つため）。
- 既存の木・鉄・鋼の個体（セーブ済み）の行き先。
- ドロップ表・図鑑・初回記録が9種に増える影響。
- スキル型の忙しさに上限を置くか（休憩に遊ぶゲームとして）。

## 5. 装飾

**決まり**

- **装飾の枠の並びは全武器共通。** 型で変えない。どの武器にも同じ並びの枠が開く。
- 枠が開く等級は **3,4,5,5,6,7,8,9**（`DECISIONS.md` `BS-17` のまま）。
- 装飾は「鍛える」ではなく「段階を上げる」（`BS-18` のまま）。
- 外すと壊れて素材に戻る（取り返しがつかない＝赤）。
- 4操作（段階を上げる・重ねる・壊す）は持ち物の画面の装飾タブに集める。
  **捨てる**はランの鞄だけ。拠点では「壊す」に一本化。

## 6. 鍛冶のレベルと、強化の失敗

**決まり**

- **鍛冶のレベル**を作る。クラフト・鍛えるで経験値が貯まる（自動で貯まる1本）。
- **レベルが上がるほど、武器・防具からもらえるステータスに補正が付く。**
  ＝ 同じ装備でも、鍛冶のレベルが高いほど強く働く。全キャラ・全装備に効く。
- **強化の失敗を入れる。ただし等級5から。** 等級1→2 … 4→5 は必ず成功。**等級5→6 以降で失敗が起きる。**
- **失敗したときは素材を失うだけ。等級は下がらない。**（原則「やって後悔したと思わせない」）
- **確定成功は専用のトークン。** 鍛冶の経験値とも遺物のポイントとも別の、3本目の勘定。
  押すときに1つ使うと、その1回は必ず成功する。
- 鍛冶のレベルは**全ジャンル共通**（ジャンルごとに分けない）。
- **鍛えられる等級の上限は無い。** レベルは補正だけを担う。素材さえあれば等級10に挑める。
  止めるのは**失敗の確率だけ**。
- **確定成功のトークンは宝箱から、たまに手に入る。**

**3つの勘定の役目（混ぜない）**

| 勘定 | 何で増えるか | 何になるか |
|---|---|---|
| **鍛冶の経験値（レベル）** | クラフト・鍛える（成功・失敗を問わず） | 武器・防具からもらえるステータスへの補正 |
| **遺物のポイント** | **強化の失敗** と **装備の分解** | 等級5〜10 の遺物。全キャラのステータスが軸ごとに上がる |
| **確定成功のトークン** | **宝箱から、たまに** | 1回ぶん、強化を必ず成功させる |

**画面**

- 「鍛冶のレベル」「次のレベルまで」「いまの補正」は押すたびに見る値なので、
  持ち物の画面の装備タブ、または鍛えるの欄の見出しの横に常に出す。
- 鍛えるの欄に、等級5以上では **成功率** と **[確定のトークンを使う]**（所持数つき）の行が増える。
  等級4以下では出さない（必ず成功するため）。1280×720 に収まる。
- 失敗したときの結果の窓に「失った素材」と「遺物に入った点数」を並べて出す。

**未決**

- 補正の形（等級1つぶんの伸びと比べてどれくらいか。レベルごとに +◯% か）。
- レベルの最大と、1レベルに要る経験値。
- 等級ごとの成功率（等級5で何%から始まり、等級10で何%か）。
- 宝箱から出る確率と、1個あたりの重み（`chests.json` の表に足す）。
- 経験値の量（かけたコスト＝等級に応じる）。

## 7. 遺物

**決まり**

- **等級5〜10 に1つずつ。合計6個。**（等級1〜4 には遺物を置かない＝失敗が起きる等級と揃えた）
- **遺物ごとに伸びる軸が違う。** 6つの軸と等級の対応（**並びは仮**。名前は10軸に揃えた）：

| 等級 | 軸 | いまの10軸にあるか |
|---|---|---|
| 5 | **攻撃** | ある |
| 6 | **HP** | ある |
| 7 | **防御**（**物理防御・魔法防御の両方**に効く） | ある（2軸に同時に効く） |
| 8 | **HP回復量** | ⚠ **無い。新しい軸**（戦闘側／回復スキルとポーション） |
| 9 | **ダンジョンの獲得ゴールド量** | ⚠ **無い。新しい軸**（ランの側） |
| 10 | **ダンジョンのレアドロップ率** | ⚠ **無い。新しい軸**（ランの側） |

- **獲得ゴールド量・レアドロップ率は、難ダンジョンとシナリオのランの両方に効く**（`DUNGEON_RUN` と `FLOOR_RUN`）。
- よって遺物は「キャラのステータス」だけでなく、**戦闘の軸と探索の軸が混ざった底上げ**になる。
  等級9・10 の2つは、強くなるというより**次の周回が太る**遺物。
- **一定のポイントで、全キャラのステータスが上がる。**
- **ポイントが貯まる口は2つだけ：**
  1. **強化に失敗したとき**
  2. **装備を分解したとき**
- **貯まる量は 失敗 ＜ 分解 ＜ 作るのにかかったぶん。**
  - 分解を失敗より多くするのは、**等級10 の遺物が貯まりにくい**ため（等級10 は失敗の機会も分解の元も少ない）。
  - それでも作るのにかかったぶんは超えないので、「作って分解」を繰り返す抜け道は塞がったまま。
- **クラフトの成功では貯まらない。** ＝ 遺物は**補填**の仕組み。
  「失敗しても、まったくの無駄にはならない」を担う（CONCEPT.md「やって後悔したと思わせない」）。
- **鍛冶の経験値とは別勘定。**
- ポイントの量は**かけたコスト（＝等級）に応じる**。等級が高いほど多い。
- **分解した装備の等級の遺物に入る**（等級6の剣を分解 → 等級6の遺物へ）。
  **等級4以下の装備を分解しても遺物には入らない。素材が戻るだけ。**
  ＝ 遺物に関わるのは等級5以上だけ。失敗が始まる等級と揃う。
  **等級10 の遺物だけは、貯まる元が「等級10 での失敗」と「等級10 の装備の分解」に限られる。**
  ここが一番遠い目標になる（意図どおり）。
- 時間をかけて強くなるのはそれでよい（上限は置かない）。**ただし1段ごとの伸びは逓減させる。**

**量産の抜け道について**

- クラフト成功では貯まらないので、安い武器を量産して稼ぐ道はそもそも無い。
- **作って分解を繰り返す道は、実装ではすでに塞がっている。** `dismantle_equipment()` は払ったぶんの **0.5倍**を返す（端数切り捨て）。
  遺物の点数は、この分解の口に1本足す形で入る。

**画面**

- **置き場は持ち物の画面の図鑑タブ。** 等級5〜10 の6行が並び、各行に「軸／貯まった点数／次の段までの残り」。その下に初回の記録（§7-2）。
- **分解**は説明の窓に [分解する]（赤）。確認の窓で「戻る素材」と「遺物に入る点数」を先に見せる。

**未決**

- 等級5〜10 と6軸の並び（上の表は仮）。
- 新しい3軸の計算の入れどころ（HP回復量は回復スキルとポーションの両方に効くか。ゴールドとレアドロップは抽選のどこに掛けるか）。
- 遺物の点数の量（失敗ぶん・分解ぶん。分解は「失敗より多く、作るのにかかったぶんは超えない」の範囲で）。
- レアドロップ率が上がると分解の元が増え、遺物がさらに貯まる（ゆるい正の循環）。逓減で抑えられるか要確認。
- **研究（`stat_boost_all` が8ノード）との住み分け**（§0-2 C）。

## 7-2. 初回の記録（遺物とは別勘定）

**決まり**

- **武器（装備）を初めて作ったら、全キャラのステータスが上がる。**
- **遺物とは別勘定。** 遺物は失敗と分解で貯まる補填、こちらは「初めて作った」という1回きりの記録。
