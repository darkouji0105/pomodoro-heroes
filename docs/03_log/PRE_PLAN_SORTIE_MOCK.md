## §1. いまの流れ（⚠ ここを前提にしてください）

```
拠点 → 依頼掲示板（手本 QuestBoard のとおり・札 3×2）
          │ 札の「受ける」「周回」／ 高難度の札の「受ける」
          ▼
      出撃届の吹き出し（⚠ 仮）：「1 僧侶 ／ 2 弓兵 ／ 3 剣士」＋「出撃する」「詰所で変える」
          │ 出撃する                          │ 詰所で変える
          ▼                                    ▼
      マップ（フロア／難ダンジョン）        詰所 →「戻る」で掲示板へ
```

- ⚠ **この吹き出しを「出撃前の画面」に置き換えたい**（⚠ 人間「⚠ 出撃前の画面を用意」）
- ⚠ 「続きから」（⚠ フロアや難ダンジョンの途中）は出撃前の画面を**通さない**（⚠ ランの途中で編成は変えない）

## §2. 決まっている数（⚠ 変えないでください）

| もの | 数 | 補足 |
|---|---|---|
| 出撃する人数 | **3人** | ⚠ 空き枠は作れない（⚠ 2人で出るは無し）。⚠ 並びの順に前へ出る |
| キャラ | いま **3人**（剣士・弓兵・僧侶）＋ 検証用3人 | ⚠⚠ **これから増える**（⚠ 10人・30人になっても使える形にしたい） |
| 編成の控え（プリセット） | **8件** | ⚠ 中身は「誰を・どの並びで・各自どのビルドか」だけ（⚠ 参照方式） |
| キャラごとのビルド | **1人3件** | ⚠ スキル・割り振り・装備の組み。⚠ ビルドを作る・直すのは育成でやる |
| 装備 | ⚠ **1つの装備を着けられるのは1人** | ⚠ 控えを呼ぶと、⚠ 他の人が着けていた装備を奪うことがある（⚠ 「剣士から鉄の剣を外しました」と知らせる） |
