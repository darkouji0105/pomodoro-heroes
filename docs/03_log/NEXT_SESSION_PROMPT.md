## ⚠⚠ この日に学んだ罠（**踏み直さない**）

1. ⚠⚠ **無名関数をシグナルにつながない。** ⚠ `self` やローカル変数を**値として捕まえる**ので、
   ⚠ 相手が消えると `Lambda capture at index 0 was freed` が出る。⚠ **中の `is_instance_valid()` は手前で弾かれるので効かない。**
   ⚠ **名前付きの関数なら Godot が解放時に自動で切る。**
2. ⚠⚠ **エラーのバックトレースは「シグナルを出した側」を指す。⚠ 壊れている受け手は出ない。**
   ⚠ 出した側を直しても減らないときは**受け手を疑う**。
3. ⚠⚠ **子の `_ready()` は親より先に走る。** ⚠ 画面が `_ready()` で子へ値を渡しても間に合わない。⚠ setter で受けて作り直す。
4. ⚠⚠ **積んである窓（キューの中）はツリーに入っていないので `@onready` が null。** ⚠ Theme は「出したとき」に控える。
5. ⚠⚠ **歩く口（`move_in_dungeon()`）はマスを踏むだけ。⚠ 戦闘は画面が起こす。**
   ⚠ だからボスまで歩くと**戦わずにボスを使い切る**。
6. ⚠ **`CanvasLayer` は `CanvasItem` ではない。** ⚠ `is CanvasItem` で弾くと黙って効かない。
7. ⚠ **Theme に定数を足した回は、`scenario=theme` を2回回さないと載らない**（⚠ 1回目で `.tres` に保存され、2回目で読まれる）。
