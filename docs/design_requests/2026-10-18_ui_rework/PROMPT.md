# 依頼：ゲーム「ポモドーロヒーローズ」の画面を作り直したい（6画面）

日本語で答えてください。添付の絵（`images/`）が**いまの画面**、添付の HTML（`reference_mocks/`）が**前回あなたに作ってもらった手本**です。見た目の決まり（色・字・部品）は手本に合わせたまま、**使いにくいところ**を直したモックを作ってください。

---

## 共通の前提（毎回これを読んでから）

- ゲーム：ポモドーロ（集中タイマー）で資源を貯め、キャラを育てて戦わせる。Godot 4 で作っている。画面は **1280×720**、横長、マウス操作
- 見た目：**紙・革・真鍮・封蝋**。暗い茶の地に、生成りの紙（角飾り・少し傾く）を置く。字は墨。主ボタンは真鍮、ふつうのボタンは革、戻るは左上
- 画面の上：左上に「戻る」と画面の題 ／ その下に紙のタブ（キャラ・詰所・鍛冶場・研究）／ 右上にお金・スタミナと、その画面で使う素材のチップ
- 画面の下：施設の帯（本部・冒険・育成・持ち物・記録・ショップ）
- 絵はまだ仮（キャラは色付きの四角に顔の絵文字、装備・スキルは線のアイコン）。**あとで1枚ずつ画像に差し替える**ので、絵の入る枠は四角いマスにしておいてほしい
- 装備の**等級は 1〜10**（等級ごとに枠の色が決まっている）。**★＝特殊効果つきの品**（レア）。装備の部位は 頭・上半身・下半身・武器・アクセサリー の5つ。装備には装飾（パーツ）を刺す枠がある
- キャラは**18人**（これからも増える）。1人ごとに **ビルドを3つ**保存できる（ビルド＝ステータスノードの振り方・スキル2つ・パッシブ・装備5つ・ルーンの設定）
- 編成は**3人**（前・中・後）。編成の控えは**8件**（3人の並び ＋ それぞれ何番のビルドか）
- スキルの枠は**2つ**。覚えているスキルは1人6つ前後（レベルで解放）
- 出してほしいもの：**画面ごとに HTML のモック1枚**（必要なら「押したあと」の2枚目）。中の数値・名前は仮でよい

## 画面ごとの依頼

### 1. 詰所（＝出撃の準備）　絵：`01_barracks_now.png` `01b_…` `02_sortie_now.png` `02b_sortie_pick_now.png` ／ 手本：`Barracks.html`

詰所と「出撃の準備」は同じ画面（依頼を受けて開くと右下に「出撃する」が出る）。

困っていること（遊んだ人の言葉）：
- 「出撃するとき編成を変えられるように」→ ⚠ **実はもう変えられる**（3つの枠を押す → 下の名簿から選ぶ）。**気づけていない**ので、変えられることが一目で分かる形にしてほしい
- 「スキルのプリセットも便利にしたい」「ビルドを詰所の画面で組んで保存できるように」→ いまビルドは枠の「ビルド1（空き）▼」で**選ぶだけ**。組む・保存するのは育成の画面（概要の下の「焼く」「適用」）でしかできない。**詰所の中でビルドを組んで保存**できるようにしたい
- 「アイコンをビルドに書いとく」→ ビルドの名前が「ビルド1」だけで中身が分からない。**ビルドの中身（スキル2つ・装備5つのアイコン）を小さく並べて**見せたい
- 「詰所のキャラ一覧もわかるようにしたい」→ 下の名簿が小さく、横に流れて切れている（18人いる）。誰が出ていて、誰が強くて、何ができるのかが分かる一覧にしたい
- 「装備も着替えられるように　詰所から」→ この回は応急で「選んだ人の装備を着替える」ボタン（育成の装備タブへ移る）を足した（`01b`）。**詰所の中で着替えられる**形が理想

残すもの：3つの枠（番号・顔・名前・役割・Lv・HP・主な値・入れ替えの◀▶）／ 右の「編成の控え」（呼ぶ・いまを残す）／ 名簿の並べ替え（Lv・名前）

### 2. 育成（キャラごとの画面）　絵：`04` `05` `06` `06b` `07` `03_character_list_now.png` ／ 手本：`Character.html` `Nodes.html` `Skills.html` `Equip.html`

左に身上書（顔・名前・Lv・ステータス10個）、右にタブ（概要・ステータスノード・スキル・装備）。

困っていること：
- 「育成画面のキャラはスキルと装備をアイコンで表示したい」→ 身上書に、**いまのスキル2つと装備5つをアイコンで**並べたい
- 「ステータスノードの上側にキャラのアイコンがあるがそれはいらない」→ 画面の上の、キャラの顔が横に並ぶ列（キャラを切り替える札）。**消したい**。⚠ 消すと「別のキャラへ切り替える」口が無くなるので、代わりをどこに置くか（例：身上書の名前の横に ◀▶、「キャラ」タブの一覧＝`03` へ戻る、など）も案を出してほしい
- 「ステータスノードもアイコンにプラス○○って書いてほしい」→ いまは「HP 1pt で +5 ・・・ +0 ［＋］［振れるだけ］」。**アイコンの中（または真横）に「+5」**と大きく出し、何が上がるかを一目で分かるようにしたい
- 「スキルのアイコンは、ふちで囲んで。あと1・2の部分もふちでかこむ。スロットにして選ぶときにスキルの一覧を見れるように」→ いまは「1 下から選ぶ」「2 下から選ぶ」が字だけで、下に候補がずらっと並ぶ。**1・2を枠（スロット）にして、押すとスキルの一覧が開いて選ぶ**形にしたい。スキルのアイコンも枠で囲む
- 装備タブ：この回に並べ替えと絞り込みの欄（「並び：いつもの順」「すべての等級」「★だけ」）を足した（`07`）。**紙の上で濃すぎる**ので見た目を合わせてほしい

### 3. 鍛冶場　絵：`08_forge_now.png` `08b_forge_relic_tab_now.png` ／ 手本：`Forge.html`

困っていること：
- 「鍛冶場は一覧でばーっとみたい」→ いまは左に細い台帳の列（名前だけ・1行ずつ）。**持っている装備をマス目でばーっと並べ**、押すと右で鍛える、の形にしたい（遺物タブの祭壇がマス目になっている＝`08b`、あれに近い）
- マス目には等級の色・★・誰が着けているかが見えるとよい。並べ替え・絞り込み（等級・★・部位）もほしい

残すもの：前 → 後の比較・成功率・素材・確定成功の札・「鍛える」「失敗しない所まで鍛える」／ 右の鍛冶の腕（Lv）

### 4. 研究　絵：`09_research_now.png`

困っていること：
- 「研究のボードも直感的にわかるようにしたい」→ いまは**字の縦の羅列**（分類・名前・効果・「◯◯の解放が必要です」・必要素材・「解放する」）。どれが開いていて、どれの次にどれが開くのかが分からない
- 研究は「ボード」単位（ボード1＝12個、ボード2＝8個）。1つずつ**前提の研究**がある（木の形）。素材を払って解放する。効果は「レベル上限 +10」「全ステータス +3」「宝箱の抽選回数 +1」など
- **前提のつながりが線で見える盤面**（スキルツリーのような）にしたい。解放済み・いま開ける・まだ開けない、が色と形で分かること

### 5. 拠点（本部）　絵：`10_base_desk_now.png` `10b_base_town_now.png` ／ 手本：`Main.html`

困っていること：
- 「拠点の配置はよくないかも」→ 机の画面（`10`）は左上に紙2枚、右上にボタン4つ、下に大きな帯（続きから・冒険・ポモドーロ・シナリオ・UIテスト）、その下にさらに施設の帯。**何を押せばいいかが散らばっている**
- 拠点の全体（`10b`）は施設の四角が9つ横に並ぶだけ
- ⚠ 「シナリオ」「UIテスト」は検証用なので無視してよい
- 主にやること＝**ポモドーロを始める・冒険に出る・宝箱を開ける・育てる**。これが自然に目に入る配置を出してほしい

### 6. 持ち物（と装備の一覧ぜんぶ）　絵：`11_belongings_equip_now.png` `11b` `11c` `11d` ／ 手本：`Belongings.html`

困っていること：
- 「持ち物や装備全般で今リスト表示だが、インベントリのように表示してクリックしたら詳しい説明が見れる方式と切り替えができるように」→ いまは台帳の行（1行に1品）。**マス目（インベントリ風）と行の表示を切り替え**られるようにしたい。マス目で押すと右の紙に詳しい説明（いまの右の紙）
- 「ソートもできるように」→ 装備はこの回に並べ替えと絞り込みを入れた（`11`）。**装飾・素材にも並べ替え**がほしい。欄の見た目も合わせてほしい
- 切り替えの見た目は、持ち物・鍛冶場・育成の装備タブで**同じ部品**にしたい
