# デザインの依頼（2026-10-18・画面の手直し）

web版の Claude にデザインを作ってもらうための一式。**ゲームのコードは入っていない。**

## 使い方

1. web版で新しい会話を開く
2. `PROMPT.md` の中身を全部貼る
3. `images/` の絵と `reference_mocks/` の HTML を添付する（⚠ 1回で入りきらなければ、`PROMPT.md` の「画面ごとの依頼」を1画面ずつに分けて頼む。そのときも「共通の前提」は毎回いっしょに貼る）
4. できたモック（HTML）は、前と同じく `docs/pomodoro-heroes-ui-docs/` の形で持ち帰る → Claude Code に「このモックから作って」と渡す

## 中身

| 置き場 | 中身 |
|---|---|
| `PROMPT.md` | web版に貼る依頼文（共通の前提 ＋ 画面ごとの依頼 6件） |
| `images/` | いまの画面の絵（1280×720・ゲームから撮ったもの）。名前の番号が `PROMPT.md` の番号と対応 |
| `reference_mocks/` | 前回 web版で作ってもらった手本の HTML（色・字・部品の見本。今の見た目はこれが元） |

## この回にコードで直したもの（デザイン不要だったもの）

- スクロールのある一覧で項目を選ぶと一番上へ戻されていた → 戻らないようにした（持ち物・鍛冶場・育成の装備とスキル・詰所・遺物・記録）
- 装備の並べ替え（いつもの順／等級の高い順／名前順）と絞り込み（等級◯以上／★だけ）→ 持ち物の装備タブと育成の装備タブに入れた
- 詰所に「選んだ人の装備を着替える」ボタン（育成の装備タブへ寄り道して、戻ると詰所）

⚠ この3つは**仮の見た目**のまま入っている（並べ替えの欄が紙の上で濃すぎる、など）。見た目は `PROMPT.md` の依頼に含めてある。
