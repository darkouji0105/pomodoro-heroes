# 依頼：「ポモドーロヒーローズ」を、ゲーム部分なしでも毎日使える集中アプリにしたい（タスク・ポモドーロ・報酬をひとつの流れに）

日本語で答えてください。添付の絵（`images/`）が**いまの画面**、添付の HTML（`reference_mocks/`）が**前にあなたに作ってもらった手本**です。見た目の決まり（色・字・部品）は手本に合わせたまま、**タスク管理 → ポモドーロ → 報酬 がひと続きで使える**画面の流れを、**押して動く HTML のモック**で作ってください。

---

## 共通の前提

- ゲーム：ポモドーロ（集中タイマー）で資源を貯め、キャラを育てて戦わせる。Godot 4 で作っている。画面は **1280×720**、横長、マウス操作（＋スペースキーで開始・一時停止）
- 見た目：**紙・革・真鍮・封蝋**。暗い茶の地に、生成りの紙（角飾り・少し傾く）を置く。字は墨。主ボタンは真鍮、ふつうのボタンは革
- ⚠ **キャラや装備の絵はしばらく用意できない。** だから当面は「ゲームを遊ばない人でも、ポモドーロとタスク管理だけで毎日使える」状態にしたい。冒険・育成・鍛冶などの画面は**この依頼では出さない**（入口が残っていても目立たなくてよい）
- 絵の入る所は四角いマスにしておく（あとで画像に差し替える）。アイコンは線のアイコンでよい
- ⚠ 絵の中の左下の「DEBUG」の欄は検証用。**無視してください**

---

## いまの仕組み（変えてよいもの・変えないもの）

### タスク（やること）

- 溜めておく ToDo リスト。日をまたいで残る
- 1件に持てるもの：**名前・フォルダ（1つ・入れ子なし・畳める）・タグ（複数・絞り込める）・色（6色から1つ）・期限（なし／今日／明日／今週中／日付）・メモ**
- 期限切れ・今日まで は小さい判（はんこ）で目立たせる。並びは自分で決めた順のまま（ドラッグで並べ替え・フォルダへ移す）
- 終わったかどうかは**自分で四角にチェック**する。終えたものはその日は線を引いて残り、**朝4:00 に一覧から消えて「記録」へ**
- **タスクごとに、集中した時間を足し上げる**（例「これまで 1時間15分」）。集中を始めるときにタスクを選ぶ／集中中に替えられる。選ばずに始めてもよい（その時間はどのタスクにも付かない）
- 書ける場所は2つ：**拠点の「今日の紙」から開くタスクの画面**（`07`）と、**ポモドーロ画面の右のサイドバー**（`02` `03`）
- ⚠ **変えないもの：タスクを終えても報酬は出さない**（細かく分けて稼ぐ遊び方を生まないため。ご褒美は**集中した時間**に付く）

### ポモドーロ

- 流れ：**加護を選ぶ（`01`）→ 集中 → 振り返り → 休憩 → 集中 …**。終えるのは「やめる」だけ（4セットで止まらず「2周目」へ続く）
- 集中 15／25／45／50分、休憩 5／10／15分、長い休憩（4回ごと）15／20／30分。休憩明けの自動開始あり（既定オフ）
- 操作：はじめる／一時停止・再開／次へ（いまのフェーズを終える）。**途中で終えても集中した分だけは数える**
- **振り返り**：集中のあと 2分の窓で「やったこと」を20字以上書く（`06c`）
- **1日の目標（分）**：設定で なし／60／120／180／240分。セットの点の右に「今日 30 / 120分」
- 集中の道具（砂時計・ろうそく・柱時計）を選べる（`05`）。小窓（デスクトップの右下に小さく出す・`06`）もある

### 報酬（⚠ ここがいちばん困っている）

- **加護**＝その日の目標の重さを3つから選ぶ（1日1回・`01`）
  - ライト：45分で ボーナス宝箱（小）
  - ミドル：45分で宝箱・90分で ボーナス宝箱（中）
  - ハード：45分ごとに宝箱・180分で ボーナス宝箱（大）
- **スタミナポーション**：集中25分ごとに1個
- 受け取りは「やめる」で拠点に戻ったときに、**箱が光って開く窓**（`09` `09b`）。⚠ この窓は**省かない**（手に入れた実感のため）
- ⚠ 変えないもの：**ポモドーロでもらったものは決して失わない**
- ⚠ **困っていること**：中身は**ゲームの中でしか意味がないもの**（宝箱の中身＝建築の素材、ポーション＝戦闘のスタミナ）。ゲームを遊ばないと、**集中しても何も嬉しくない**

### いまの困りごと（まとめ）

1. **3つがばらばら**：タスクは拠点の紙／タスクの画面、ポモドーロは別の画面、報酬は「やめて拠点に戻ったとき」に初めて出る。**集中している最中に「あとどれだけで何がもらえるか」が見えない**
2. **目標が2つある**：加護（45／90／180分）と、設定の「1日の目標（分）」。どちらを見ればいいか分からない
3. 毎回最初に**加護を選ぶ画面**を通る（1日1回だが、初めての人には意味が分からない）
4. 報酬がゲームの外で意味を持たない（上の「困っていること」）

## 作ってほしいもの

**1枚の HTML で、押すと画面が切り替わるモック**にしてください（タイマーは早回し（1秒＝1分など）で動くと流れが見やすい）。画面はおおよそ次の5つ。足す・まとめる・減らすは自由です。

### A. 今日の画面（起動したら最初に出る）

- 今日のタスク（期限切れ・今日まで が目立つ）と、**「これで集中」**の入口
- 今日の集中（分）と**今日の目標までの進み**、**次の報酬まであと何分**
- 加護の選び方をここに溶かすか、目標と一本化する案（困りごと2・3）

### B. 集中中

- タイマー（道具の絵）・いまのタスク・一時停止／次へ
- 右のサイドバーのやることリスト（行を押す＝いまのタスクにする・四角＝終える・下で足す）はいまの形を残してよい
- ⚠ **報酬までの進みが集中中にも見える**こと（例：「宝箱まであと 12分」・ポーションの溜まり具合）

### C. 振り返り → 休憩

- 振り返り（やったことを書く）と、休憩のタイマー
- **その1セットで何が溜まったか**が小さく分かる（受け取りの窓とは別。窓は最後）

### D. 受け取り（やめたとき）

- いまの「箱が光って開く窓」の手応えは残す
- ゲームを遊ばない人にも嬉しい形にしたい（下の「報酬の案」）

### E. 記録

- 今日・今週の集中時間、タスクごとの時間、終えたタスクの一覧（いまは記録の画面の1枚のタブ・`10`）
- 毎日続けた日数などの見せ方も案があれば

## 報酬の案を2つ出してください（⚠ ここは決めきれていません）

条件：
- **集中した時間**に付ける（タスクを終えた数には付けない）
- もらったものは失わない
- いまのゲームの報酬（宝箱・ポーション）は**残す**。ゲームを再開したときにそのまま使える
- そのうえで、**ゲームを遊ばない人にも「集中してよかった」と思える何か**を足す

たとえば（参考・これに縛られなくてよい）：スタンプ帳／続けた日数／集めて飾る棚／今日の集中の絵日記 など。**2案**を、A〜E の画面にどう出るかまで含めて見せてください。
