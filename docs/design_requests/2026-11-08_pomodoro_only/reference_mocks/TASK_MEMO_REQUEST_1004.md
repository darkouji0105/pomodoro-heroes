## §1. このゲームとタスクのメモ

- ポモドーロ・テクニック（25分集中＋休憩）のタイマーと、RPG（拠点・育成・ダンジョン）が一体になったゲーム。集中した時間がゲームの報酬になる
- 見た目は「夜の拠点の机の上に、羊皮紙の書類が置かれている」。情報は必ず紙の上に書き、状態は赤い判（はんこ）で押す（手本 UI_GUIDE）
- **タスクのメモ**＝やることを溜めておく ToDo リスト。集中を始めるときに、リストから「いま何をやるか」を選べる。選んだタスクには、集中を1回終えるごとに「ポモドーロ 1回」が数えられる

いまの流れ：

```
拠点（本部）
 └ 左上の壁に「やること」の紙（まだのタスクが全部・溢れたら紙の中でスクロール）
      │ 行か「ひらく」を押す
      ▼
   タスクの画面（左＝一覧 ／ 右＝選んだタスクを詳しく）→「戻る」で拠点

拠点の下の「ポモドーロ」
 └ 加護（今日の目標時間）を選ぶ → 集中を始める前の画面
      ・1行の題の欄（自由に打てる）
      ・その下に「リストから選ぶ」「リストに足す」
      ・選ぶと題がタスクの名前になる。選んだあとに題を書き換えると、タスクの名前も変わる
      │ はじめる
      ▼
   集中（砂時計の絵が減っていく）→ 振り返り → 休憩 → 次の集中 …
      ・右上に「リスト」「やめる」。「リスト」を押すと、まだのタスクの紙が下に開く（見るだけ）

記録（施設の帯から）
 └ タブの5枚目「終わったタスク」（終えた日・題・ポモドーロの回数。新しいものが上）
```

**いまの画面で気になっていること**（設計役の見立て。人間はまだ見ていない）

- 拠点の紙：期限の判（「期限切れ」「今日まで」）が大きく、題が「企画書の下書…」と切れる。紙の大きさ（340×300）が拠点で邪魔でないか分からない
- タスクの画面：チェックの箱が革色の四角で紙の上で重い。▲▼のボタンが大きく、1行が太い。行の下の小さな字（期限・タグ・回数）が「…」で切れる
- 期限の決め方が「なし ／ 今日 ／ −1日 ／ ＋1日」だけで、先の日付を入れるのが手間
- ポモドーロの「リストから選ぶ」「リストに足す」が地味で気づきにくい。選んだかどうかが「リストのタスクとして数えます」の1行でしか分からない
- 集中中の「リスト」の板が砂時計の右に被る

## §3. 変えないこと（決まっている）

| もの | 決まり |
|---|---|
| タスクの中身 | 名前 ／ メモ ／ 期限（日付・無しもある）／ 色（**6色から1つ**）／ タグ（自由に打てる・何個でも）／ 並べる順 ／ ポモドーロの回数（自動で数える） |
| 入れないもの | 「見込みのポモドーロ数」は入れない。タスクと報酬（ゲームのご褒美）は繋げない |
| 書ける場所 | 拠点（タスクの画面）とポモドーロの画面の両方 |
| 拠点の紙 | まだのタスクを**全部**出す（件数で切らない・多いときは紙の中で送る）。押すとタスクの画面 |
| 終わった | 自分でチェックする。チェックしたものは**その日のうちは線を引いて一覧に残り**、朝4:00 に一覧から消えて記録の「終わったタスク」へ移る（記録は上限なし） |
| 期限 | 期限を過ぎた・今日が期限のものは、**拠点の紙と一覧で目立たせる**。並びは自分で決めた順のまま（期限で並べ替えない） |
| 数える時 | 集中のタイマーが0になったとき、選んでいたタスクに +1。選ばずに始めてもよい（そのときはどれにも数えない） |
| ポモドーロの題 | 1行の題の欄は残す。「リストから選ぶ」「リストに足す」を足す。選んだあとに題を書き換えると、タスクの名前が変わる |
| 消す | 消せる。確かめの窓を挟む。消したものは記録にも残らない |
| 色 | 6色はいまの値（赤 `#9c3a2e` ／ 黄 `#b98a2c` ／ 緑 `#5f7d4f` ／ 藍 `#2f5f8c` ／ 紫 `#6a4a7c` ／ 茶 `#6e5a43`）。変えたい案があれば別の案として出してよい |
| 字 | **絵文字は出せない**（ゲームのフォント NotoSansJP に絵文字が無い）。🍅 などは使わず、字か手描きの小さな絵で |
| 解像度 | 1280 x 720。拠点の右上には通貨3つと素材の帯（最大16個）が並ぶ。下には施設の帯（高さ約76） |

## §4. 描いてほしいもの

1. **拠点**（紙あり・タスク8件で溢れる姿）。⚠ 右上の素材の帯・下のボタンと施設の帯も描いて、紙との兼ね合いが分かるように
2. **タスクの画面**（一覧 ＋ 詳しく）。終えたタスク（線）・期限切れ・今日まで・タグで絞っている姿が1枚に入ると嬉しい
3. **期限を決めるところ**（§5 Q4 の答え）
4. **ポモドーロの集中を始める前**：選んでいない姿 ／ 選んだ姿
5. **リストから選ぶ窓**
6. **集中中にリストを見る姿**
7. **消す確かめの窓**（手本 `Confirm.html` のまま描けるなら省いてよい）
8. **記録の「終わったタスク」のタブ**（何十件・何百件になったときの見せ方も）

## §6. 今の手本の部品で使えるもの

- 紙・紙の見出し・紙のタブ・台帳の行（下に点線の罫・選んだ行は明るい紙＋左に真鍮の線）・判・傾いた紙・施設の帯・紙の上の小さな札（並んだ選択肢）・確かめの窓（題の帯・実行は赤）
