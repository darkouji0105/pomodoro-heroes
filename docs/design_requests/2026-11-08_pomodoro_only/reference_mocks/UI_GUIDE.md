# ポモドーロヒーローズ UIの決まり（2026-09-26）

> 画面の見本は `screens/*.html`（静的HTML）と `screenshots/*.png`。一覧は `index.html`。
> 色・寸法の数値は `ui_tokens.json`、部品の見本は `ui-reference.html`。
> モックの絵はすべて仮。装備の種類の絵・キャラ・広間・家具は、用意した画像に差し替える。

## 1. 方針

画面は「ギルドマスターの机に書類を広げる」形にそろえる。プレイヤーはギルドマスターで、3人の冒険者に指示を出し、判を押して送り出す。

- **暗い地は木と革**：画面の地、見出しの帯、下の施設の帯、ボタン。
- **情報は紙の上**：一覧・説明・記録・申請はすべて羊皮紙の書類。暗い箱で囲まない。
- **区切りは墨の線**：太い下線（見出し）、点線の罫（行）、縦の罫（欄の区切り）。
- **状態は判で押す**：済・受理・昇級・可・使用中など。通知ではなく、その紙の事柄の状態。
- **受付は置かない**：3人が直接マスターに話しかける。
- **戦闘だけは例外**：読みやすさを優先して、質感を抑えた暗い画面のままにする。

本部（ホーム）は眺められる広間にし、段階的に作る。段階1は家具固定の広間、段階2はデスクトップの小窓（ポモドーロのあいだだけ）、段階3は家具を置く。

## 2. 色と文字

1つの色は1つの意味だけに使う。等級の色（IconConfig の10段・BS-19）はほかの意味に使い回さない。

| 名前 | 色 | 使いどころ |
| --- | --- | --- |
| 夜の床 | #1B1512（質感つき #1D1612） | 画面の地 |
| 板 | #2A201A | 暗い面・戦闘の欄 |
| 革 | #4A3526 | 既定ボタン・戻る |
| 真鍮 | #B98A2C | 主ボタン（1画面に1つ） |
| 灯り | #D4A640 | 選択・線・光（鍛えられる） |
| 封蝋 | #9C3A2E | 危険・しおり紐・判 |
| 羊皮紙 | #E9DCC0 | 書類 |
| 明るい紙 | #F4EAD3 | 選んでいる行 |
| 墨 | #2B2118 | 紙の上の字 |
| 薄墨 | #6E5A43 | 紙の上の小さい字（これより薄くしない） |
| 罫 | #C2AE88 | 点線の罫 |
| 真鍮の墨 | #9C7424 | 紙の上の強調・選んでいる行のふち |
| 削れ | #C0624F | HPの削れた上限のふち |
| 特殊効果 | 墨 #1F1A17 に金 #E0B85C | 特殊効果の札と星 |

文字は4種類。

- **見出し**：Shippori Mincho B1（700〜800）。字間を広く取る。
- **数字**：Noto Sans JP 900・等幅。数字は明朝にしない。戦闘の数字には黒い太いふち。
- **本文**：Noto Sans JP 400〜500。
- **サイン**：剣士 Yuji Boku、弓兵 Klee One、僧侶 Zen Kurenaido（サインの字だけ）。

## 3. 部品

| 部品 | 見た目 | 決まり |
| --- | --- | --- |
| ボタン | 真鍮・革・素（ふちだけ）・封蝋（赤）・戻る の5階層 | 真鍮は1画面に1つ。赤は取り返しがつかない操作だけ。戻るは左上。紙の上で使えないものは点線 |
| 紙（書類） | 羊皮紙に繊維の質感と焼け、四隅に真鍮の角飾り、少し傾ける | 情報は必ず紙の上。見出しは明朝＋太い下線＋菱形の飾り罫 |
| 紙の見出しタブ | 紙の上の縁から飛び出す見出し | 開いているタブは紙と同じ色で背が高い（46）。ほかは一段濃く低い（38） |
| 台帳の行 | 点線の罫で区切る行 | 選んでいる行は明るい紙＋左に真鍮の墨の線。使えない行は薄く、鍵つき |
| 点線リーダー | 項目名から値まで点線 | 目次のような行（概要タブ・素材・記録の合計） |
| 記入欄 | 下線だけの欄 | ビルドの選択など |
| 判 | 赤い四角や丸の印を傾けて押す | 状態を表す（済・受理・昇級・可・使用中・枠1・成功・失敗） |
| 身上書 | 写真の額（テープ留め）、職の紋、ステータスの細い棒、本人署名 | 育成・詰所・昇級で使う。ステータスの名前を出すのはここだけ |
| 会話 | 顔＋明るい紙の吹き出し＋返事2つ | 話すのは1人ずつ。返事の片方はそのまま行き先 |
| HPバー | 緑＝いまのHP、暗い＝戦闘で減った、赤いふちだけ＝削れた上限 | 全体の長さはいつも元の上限 |
| 状態アイコン | 地の色＋白い絵、文字なし（BT-3） | 良い＝青、悪い＝赤、復活＝黄。右下に重ねた数。触れると名前 |
| アイテムのアイコン | 枠の形＝種類、ふちの色＝等級 | 装備は四角、装飾は八角、素材は丸、消耗品・宝箱は角丸。左上に等級、下に装飾の枠 |
| 説明の窓 | ピンで留めた紙 | 中身だけ送れる。操作（着ける・鍛える・刺す・分解）は下に固定。細かい数字は「詳しく（Alt）」 |
| 確かめの窓 | 後ろを暗くした紙の窓、角に「戻せない」の判 | 開いたとき「やめる」が選ばれている。いちばん重いもの（やり直す）は長押し |

## 4. 印の決まり

1つの印は1つの意味だけ。通知はしおり紐で確定。

| 印 | 伝えること | 出す場所 | 消えるとき |
| --- | --- | --- | --- |
| しおり紐（赤） | 見てほしいことがある | 右上の縁。施設の帯・掲示板のタブ・宝箱（数字入り）・品（細く短く） | 見たら |
| 光（真鍮） | いまの素材で鍛えられる | 品のふち・鍛冶場へのボタン | 鍛えられなくなったら |
| 判 | その紙の事柄の状態 | 紙の上 | 状態が変わったら |
| ふちの色 | 等級 | 品の枠 | 変わらない |
| +数 | 一覧で出していない能力の数 | 一覧の行 | 変わらない |
| 星（墨に金） | 特殊効果がある（動きが変わる） | 一覧の行・説明の窓の札 | 変わらない |
| 吹き出し | キャラが話したい（通知ではなく会話の入口） | 広間のキャラ・身上書 | 話したら |

- **ステータスの名前**：身上書だけ名前を出す。ほかはアイコン＋数字で、触れると名前の札。
- **細かい数字**：ふだんは大きな数字だけ。「詳しく（Alt）」で伸び方や出どころを開く。
- **削れた上限**：HPの上限の目減りは赤いふちだけで描く（戦闘の減りと見分けるため）。
- **集中中は何も知らせない**。光はしおり紐より静かな合図。

## 5. 画面の一覧と流れ

下の施設の帯は 本部・詰所・鍛冶場・持ち物・記録 の5つ。ファイル名は `screens/` と `screenshots/` 共通。

| まとまり | 画面 | ファイル | 中身 |
| --- | --- | --- | --- |
| 入口 | タイトル | Title | 看板・続きから／はじめから／設定／終わる |
| 拠点 | 本部（広間） | Main | 家具が入口：掲示板→依頼、砂時計→集中、宝箱→開ける、本棚→記録。3人が話しかける |
| 拠点 | 依頼掲示板 | QuestBoard | タブで 通常の依頼／高難度の依頼。高難度は難ダンジョンごとに札 |
| 拠点 | 詰所 | Barracks | 3人の身上書・出撃届・編成の控え |
| 拠点 | 育成 | Character / Nodes / Skills / Equip | 左に身上書、右に紙のタブ（概要・ステータスノード・スキル・装備） |
| 拠点 | 昇級 | LevelUp / LevelUpDone | 昇級申請書 → 判が落ちる結果 |
| 拠点 | 修練の道が開いた | PassiveUnlock | 開いたパッシブと次の目標 |
| 拠点 | 持ち物 | Belongings（見本 RichItemMulti / RichItemFx / RichItemMax、広い画面 BelongingsWide） | タブで 装備・装飾・素材。装備は部位で縦のタブ。右に説明の窓 |
| 拠点 | 鍛冶場 | Forge / ForgeResult / ForgeResultFail | タブで 鍛える・作る。結果は成功・失敗 |
| 拠点 | 記録 | Records | タブで アイテム図鑑・集中の履歴・キャラの情報・ダンジョンの情報 |
| 拠点 | 届いた宝箱 | Chest | 棚の帳面 → 開ける → 受け取り帳 |
| 集中 | 加護を選ぶ | Pomodoro | ライト・ミドル・ハード |
| 集中 | 集中中 | Focus / FocusSkins | 道具（砂時計・ろうそく・柱時計）ごとの見た目 |
| 集中 | 集中の道具 | PomoSkin | ポモドーロの見た目を選ぶ |
| 集中 | デスクトップの小窓 | Companion | ポモドーロのあいだだけ。集中中は静か、休憩で話しかける |
| ダンジョン | 潜る準備 | DungeonGate | 坑道の縦図（10層ごとのつまみ）・ノルマ札1枚 |
| ダンジョン | 署名 | Sign | 3人のサイン → マスターの判 |
| ダンジョン | マップ | DungeonMap | 羊皮紙の地図・たいまつの灯り・3人の上限 |
| ダンジョン | 戦闘 | Battle | 丸い駒・状態アイコン・数字は太いゴシック |
| ダンジョン | レリック／わかれ道／ショップ | DungeonRelic / DungeonFork / DungeonShop | 紙のカード・出る／もう10層・値札 |
| ダンジョン | 帰還 | DungeonResult | 帰還報告書（踏破の層数）と持ち帰った品 |
| 共通 | 確かめの窓 | Confirm | 分解・その場で降りる・やり直す |
| 共通 | 空っぽの状態 | EmptyStates | 持ち物・集中の履歴・宝箱が空のとき |
| 共通 | 設定 | Settings | 表示・音・ポモドーロと小窓・データ |
| 参考 | UIパーツ／印の決まり／アイコン／状態アイコン／通知 | Parts / Signals / Icons / Status / Notify | 部品の見本 |

おもな流れ。

1. 依頼：本部 → 掲示板 → 潜る準備 → 署名 → マップ → 戦闘 … → わかれ道 → 帰還
2. 育成：詰所（身上書）→ 育成のタブ → 昇級／鍛冶場 → 結果
3. 集中：本部の砂時計 → 加護を選ぶ → 小窓（ポモドーロ中）→ 休憩で話しかける → 本部

途中でやめたときの挙動と、ダンジョンの中の窓（通路のできごと・拾いもの・鞄の入れ替え など）は別の資料（DECISIONS.md など）に従う。

## 6. 画面の大きさと動き

基準は 1280×720。大きい画面では拡大せず、広くなった分だけ見える範囲を増やす（見本：BelongingsWide、1600×900）。

- **横いっぱい**：見出しの帯・下の施設の帯・地の木目。
- **広がる**：一覧（見える行が増える）・広間（奥行き）・地図。
- **幅を固定**：説明の窓・確かめの窓・身上書。
- **操作**：マウスとキーボードだけ。コントローラーは考えない。名前や見比べは「触れたら出る」、キーボードで選んだときも同じ。
- **動き**：紙が少し傾く、判が落ちる、札が下から跳ねる、キャラが揺れる、署名を書く。設定の「動きを減らす」で全部止める。
- **署名の動き**：剣士 → 弓兵 → 僧侶の順に書き、最後にマスターの判が落ちて紙が少し沈む。全部で約5秒。

## 7. Godot に移すとき

モックの見た目を、Godot のテーマ（Theme）と部品のシーンに写す。画面ごとに作り込まない。

| 項目 | やり方 |
| --- | --- |
| テーマ | 「紙・革・真鍮・封蝋・素」の StyleBox を1つのテーマにまとめる。ボタン5階層は type variation |
| 紙の質感 | モックは計算で作った模様。Godot では小さな画像をくり返し貼る（繊維・木目）。焼けは内側の影 |
| 紙の角飾り | 伸ばしても崩れない 9スライス（NinePatchRect）で1枚にする |
| 見出しタブ | 紙と同じ StyleBox の上辺だけ角丸。開いているタブは高さ 46、ほかは 38 |
| フォント | 明朝・ゴシックの2本が基本。サインの手書き3本は使う字だけに絞る。どれも OFL |
| 画面の大きさ | 引き伸ばしは canvas_items ＋ expand |
| 広間 | 別のシーン。背景（床・壁・窓）は1枚絵を選ぶ形、家具とキャラはその上に置く。小窓は同じシーンを小さく映す |
| 画像 | モックの絵はすべて仮。用意した画像に差し替える。等級の色はいまの10段のまま |
| ホバー | 名前の札は自前の小さな紙で作る（未確定：標準 Tooltip でよければそちら） |
