## 【1】題目を決める — あなた

⚠⚠ **`docs/NEXT_STEPS.md` の一番上「これからの回（仮）」の表から選ぶ**（2026-09-21 に新設）。
⚠ **回は前もって仮で並べてある。⚠ 人間はいつでも並べ替えてよい**（⚠ 思いつきが最優先）。

⚠⚠ **新しく宿題が出たら、⚠ その回の「残っているもの」に積まず、⚠ この表のどれかの回へ入れる。**
⚠ **これをやらないと、⚠ 宿題が回ごとの節に散って、⚠ 全体でいくつ残っているか誰にも分からなくなる**
（⚠ 2026-09-21 の見直しで実際にそうなっていた）。

⚠ **回が終わったら、⚠ 表からその行を消して、⚠ 下に終わった回の節（§0-UI-◯）を書く。**

## 【2】現状を `grep` で取る — 設計役

⚠⚠ **ドキュメントの「実装済み」を信じない**（`CLAUDE.md` 1番）。
⚠ **6回続けて、台帳の記述と実コードがズレていた。**

- ⚠ **先に読むのは `docs/DECISIONS.md`**（⚠ いま効いている値）。⚠ **`PLAN_◯◯.md` は経緯を知りたいときだけ**
- ⚠ 関数の中身を `grep` で見る。⚠ 「対応済み」と書かれた関数が空実装だったことがある
- ⚠ **読んだ結果ドキュメントが間違っていたら報告する。⚠ 勝手に直さない**

## 【3】方針と選択肢を出す — 設計役

- ⚠⚠ **大きい変更は先に方針を出して合意を取る。⚠ 合意なしにファイルを書き換えない**
- ⚠ 選択肢には**代償**を必ず書く。⚠ 推しを1つ挙げる（⚠ 人間は覆してよい）
- ⚠⚠ **器（関数・状態のキー・画面）が作り直しになるものだけ `EXEC_◯◯.md` を書く**。
  ⚠ つまみ1つ・見た目を消すだけのものは書かない

## 【4】裁く — あなた

⚠ **人間の言葉はそのまま記録する**（⚠ 要約しない）。⚠ 覆したときは**覆した相手も書く**。

## 【5】着手の前に「変わるはずの数字」を1行書く — 設計役

> ⚠ **この変更を入れると、◯◯の数字が A から B に変わるはず**

- ⚠ 書くのは**生成・分布・レイアウト・数え方が変わるもの**だけ（⚠ 全部に義務づけない）
- ⚠⚠ **書けなかったときが本番。** ⚠ 「数字にできない」＝**絵か人間でしか見られない**と着手前に分かる

## 【6】実装する — 設計役

- ⚠ **インデントはタブ**（`.gd`）
- ⚠ **編集したら `grep` で当たったことを確認する**（`CLAUDE.md` 2番）
- ⚠ **まとめて書き換えたら `git diff <ファイル> | grep "^-func"` を見る**（`CLAUDE.md` 9番。⚠ 0件が既定）
- ⚠ **1つ入れるごとにコミット。** ⚠ メッセージは日本語
- ⚠⚠ **止まる条件**：⚠ 1つの症状に**2手まで** ／ ⚠ 1ファイルへの書き込みが2回失敗したら中止 ／
  ⚠ 同じ箇所を3回直すことになったら設計を見直す

## 【7】検証する — 設計役

| どこを見るか | どうやって |
|---|---|
| **ログ** | `--headless` でシナリオを回し、`godot.log` を読む |
| **ファイル** | `save_slot_0.json` / `battle_last.jsonl` を読む |
| **画面（在るか・並び・大きさ・形）** | ⚠⚠ **`scenario=shot` で絵を撮って読む**（2026-09-21〜） |
| **画面（色・活性・手応え・遷移・気づけるか）** | ⚠ **人間だけ**（⚠ 【10】へ送る） |

- ⚠⚠ **人間に渡す前にヘッドレスを1回通す。⚠ ロード時の赤・黄はそこで潰す**
- ⚠ **「動きました」と書かない。⚠ 取れたものだけを根拠にする**
- ⚠ **ログを読む前に自分でヘッドレスを走らせない**（⚠ `godot.log` は5本で押し出される）

## 【8】記録する — 設計役

| どこへ | 何を |
|---|---|
| `docs/DECISIONS.md` | ⚠⚠ **決まった値**（⚠ 1決定＝1行。⚠ 覆したら上書きし、旧文は取り消し線で1行） |
| `docs/NEXT_STEPS.md` | ⚠ **この回**（⚠ 決定・入ったもの・実測・報告・残り） |
| `docs/PROJECT_STATUS.md` | ⚠ 現在地が動いたときだけ |

- ⚠⚠ **値を書くのは `DECISIONS.md` だけ。⚠ `NEXT_STEPS` には番号を書く**
- ⚠⚠ **`IMPL_LOG_◯◯.md` は書かない**（⚠ 2026-09-21 に廃止）
- ⚠ **`NEXT_STEPS.md` は直近3節まで。⚠ 溢れたら `docs/03_log/NEXT_STEPS_<年月>.md` へ移す**

## 【9】push — 設計役

- ⚠ **聞かずにしてよい**（2026-09-20 の人間の許可）
- ⚠ **`main` 以外へ押さない** ／ ⚠ **強制 push はしない** ／ ⚠⚠ **赤が残っているものは押さない**

## 【10】「見る回」で実機を見る — あなた

> ⚠⚠ **人間の言葉（2026-09-21）：⚠ 「実機確認が重いが重要でもある　⚠ だから頻度を減らして一気にチェックしたい」。**

- ⚠⚠ **1タスクごとに渡さない。** ⚠ **「絵で判断できなかったもの」が3件たまったら「見る回」を置く**
- ⚠ **回数では数えない。⚠ 数えるのは中身**（⚠ 絵で潰せた回は人間の番が来ない）
- ⚠ 渡すもの：⚠ **撮った絵** ＋ ⚠ **絵で判断できなかったものだけの短いリスト**
- ⚠ **人間が遊んだあとの `godot.log` は設計役が読む**（⚠ 貼ってもらわない）

## 人間にしかできないこと（**設計役が依頼する**）

| | なぜ |
|---|---|

| **モックを描く** | ⚠ 見た目の正解を持っているのは人間 |
