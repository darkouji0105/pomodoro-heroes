## 2. 作業場

- ⚠ 等級1の通常品21件：`craft_<item_id>`・鍛冶の欠片（`forging_material_1`）×10・1800秒・初めから解放
- ⚠ 特殊効果のくじ `craft_equip_rare`：鍛冶の結晶（`forging_material_3`）×10・10800秒・特殊効果5品から1つ（重み同じ）。⚠ 作ったものは等級1（⚠ `EQ-11`。⚠ 落ちるときの「等級9以上」は `EQ-13` のまま）
- ⚠ 画面は作り直さない（⚠ 行の字は inputs / outputs から組み立てる作り）

## 3. ドロップ（`dungeon.json`）

- ⚠ 木・鉄・鋼の剣の行を消し、⚠ 通常品21件（戦闘 1 ／ ボス 6）・特殊効果2件（戦闘 1 ／ ボス 3）を足す

## 4. コード

1. `GameManager.ITEM_MASTER_WEAPON_GENRE` ／ `get_weapon_genre(item_id)` ／ `get_character_weapon_genre(character_id)` ／ `can_wield(character_id, item_id)`
2. `get_equip_reject_reason()`：⚠ スロット一致の次に「ジャンル違い」
3. `get_item_stats_at_grade()`：⚠ マイナスは伸ばさない
4. `load_state()`：⚠ `LEGACY_ITEM_IDS` で置き換え（個体・持ち物・図鑑・見た品・ランの鞄と拾い待ち）→ ⚠ 装備の正規化のあとに「持てない武器を外す」
5. 画面：⚠ 育成の装備タブの候補をジャンルで絞る ／ ⚠ 値の表示を符号つきに（`+`決め打ちをやめる）

## 5. 完了条件

### ログ（`ui_flow`）
1. 弓兵は剣を着けられない・剣士は着けられる（`get_equip_reject_reason()`）
2. 育成の装備タブの武器の候補に、持てないジャンルが出ない
3. 細身の剣 等級5 の HP は −10 のまま・攻撃速度は等級1より大きい
4. 作業場に装備のレシピが並び、作って受け取ると装備の個体（等級1）が増える
5. 古い剣を着けたセーブを読むと、細身の剣に置き換わり、弓兵の武器は外れる
