```
ボスを倒す
  → 【新】わかれ道の画面（1枚）
      ・フロアを踏破したこと
      ・⚠⚠ 何を手に入れたか（⚠ 人間「⚠ 何を手に入れたか見れる画面を」）
      ［さらに潜る］ → ショップ → 次のフロアのマップ
      ［ここで戻る］ → 拠点へ直行（⚠ 鞄の中身は持ち帰る）
```
