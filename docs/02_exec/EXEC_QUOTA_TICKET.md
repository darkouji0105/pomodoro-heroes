## 4. 作り方

- ⚠ **品** `quota_ticket`（`items.json`・消耗品・持ち物）。⚠ 定数 `GameStateKeys.ITEM_QUOTA_TICKET`
- ⚠ **上限**は Balance（⚠ `DungeonConfig` か新しい欄）＝3。⚠ 数える口 `get_quota_ticket_count()`
- ⚠ **ショップ**：⚠ `daily` に棚を1つ（⚠ 金貨・1枚・在庫1）。⚠ `purchase_shop_item()` の判定に「⚠ ノルマ札を上限まで持っていたら買えない」を足す（⚠ 状態を変える前）
- ⚠ **入る**：⚠ 新しい口 `enter_dungeon_with_ticket(dungeon_id)`＝⚠ 札の判定 → `start_dungeon_run()` → 札を1枚減らす（⚠ 入れなかったら減らさない）。⚠ `start_dungeon_run()` は札を見ない（⚠ 検査・続きの口を変えない）
- ⚠ **画面**：⚠ 出撃の準備（難ダンジョン）＝帯に「ノルマ札 1枚（n → n−1）」・⚠ 無ければ出撃できない理由 ／ ⚠ 掲示板の難ダンジョンの札＝「ノルマ札 n / 3」・⚠ 0 なら「ノルマ札が要る」で押せない（⚠ 潜っている途中の「続きから」は押せる）
