## 1. ⚠ 先に決めたこと（**設計役の決め**）

### 1-1. ⚠ フロアの固定報酬から宝箱を外す

⚠ **いまフロアは `rewards.chest_id` で「1周につき宝箱1個」を積んでいる。⚠ これを外す。**
⚠ **理由：宝箱は移動に紐づく（`PLAN_SCENARIO_MAP.md` §4）。⚠ 両方あると二重になる。**
⚠ **`_grant_stage_chest()` は `chest_id` が無ければ何もしない（黄も出さない）ので、⚠ 関数は触らない。**

### 1-2. ⚠ `chest_id` はフロアの欄に**書き下す**（IDから切り出さない）

```
"chest_ids": {
  "common": "floor_1_common", "rare": "floor_1_rare",
  "epic": "floor_1_epic", "legendary": "floor_1_legendary"
}
```

⚠ **`floor_id` から数字を切り出して `"floor_%d_%s"` を組み立てない。**
⚠ **理由：装飾で同じことをやって事故った**（⚠ **`item_id` からは切り出さない・必ず欄で引く＝`game_manager.gd:143` のコメント**）。

### 1-3. ⚠ 深度補正はレアリティの重み表を層で切り替える

⚠ **`adventure_config.gd` に4本の配列を置く。⚠ 添字は「着いたノードの層 − 1」。**
⚠ **`_roll_weighted_table()` は触らない**（`PLAN_SCENARIO_MAP.md` §4-2 の4）。

### 1-4. ⚠ 古い `stage_1` / `stage_2` / `stage_3` の宝箱は消す

⚠ **ハズレ枠（`weight: 70` の空欄）を持っているのはこの3件だけ。⚠ 中身ごと `floor_*` 20件に置き換わるので、⚠ エントリごと消す。**
⚠ **`generic` / `bonus_small` / `bonus_medium` / `bonus_large` は残す**（⚠ **`protection_*.tres` の `ChestScheduleEntry` が指している。⚠ 消すとポモドーロの加護が黙って止まる**）。

### 1-5. ⚠ `weapon_steel_sword` を `floor_5_legendary` に入れる

⚠ **宿題26「`weapon_steel_sword` がどこからも出ない」がこれで閉じる。**

## 3. `adventure_config.gd` に足す欄

```
@export var floor_chest_chance_pct: int = 35          # 移動1回あたりの出現率（％）
@export var floor_chest_weight_common:    Array[int] = [70, 60, 50, 40, 30]
@export var floor_chest_weight_rare:      Array[int] = [25, 30, 33, 35, 35]
@export var floor_chest_weight_epic:      Array[int] = [ 5,  9, 14, 20, 25]
@export var floor_chest_weight_legendary: Array[int] = [ 0,  1,  3,  5, 10]
```

⚠ **添字は「着いたノードの層 − 1」。⚠ 配列より深い層に着いたら末尾を使う。**
⚠ **各列の合計は100。⚠ 奥ほどレジェンダリーが出やすい＝メモの「奥ほど良い物が出やすい」。**
