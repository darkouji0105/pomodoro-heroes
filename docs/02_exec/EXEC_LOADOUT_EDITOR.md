## 2. 器

- `scenes/ui/components/loadout_editor.gd`（`class_name LoadoutEditor`・2画面で使う＝components/）
  - 中身＝真ん中（上に呼び出し元の欄 ／ スキル2枠 ／ 装備5枠）＋ 右（装備の候補 ／ 何も選んでいないときは呼び出し元の欄）
  - 呼び出し元が変える3か所＝`top_builder`（真ん中の上）・`idle_builder`（何も選んでいない右）・`forge`（「鍛える」を出すか）
  - 合図＝`changed(text)`（変えたところの一言）・`forge_requested(instance_id)`
  - 自分で `character_growth_changed` / `equipment_instances_changed` を受けて描き直す（⚠ 選んでいる枠・候補は持ち越す）
- 詰所の窓（`BuildEditWindow`）＝左（ビルド1〜3・ステータス）＋ `LoadoutEditor` ＋ 下（3つのボタン）。⚠ 窓は左と下だけ描き直す（⚠ 部品を作り直すと選んでいる枠が消える）
- 育成（`TrainingScreen`）＝タブ「スキル」「装備」を **「スキル・装備」の1枚**に。⚠ 外から開く口（`TRAINING_TAB_SKILLS` / `TRAINING_TAB_EQUIP`）は両方ともこの1枚へ（装備なら武器の枠を選んだ姿）
  - 何も選んでいない右＝通常攻撃とパッシブ（⚠ 前のスキルのタブの下の欄＝`GR-8`）
  - 「鍛える」＝出す（⚠ 鍛冶場は寄り道・戻ると同じ人・装備の枠）
- 消すもの：`training_skills_page.gd`・`training_equip_page.gd`（⚠ 中身は部品と育成へ移す）
