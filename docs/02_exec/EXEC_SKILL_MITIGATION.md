## 2. ⚠ 事故りやすい箇所

### 2-1. ⚠ 無限反射（**決定1の代償**）

⚠ **両者が反射を持つと、殴る → 反射 → その反射を反射 … で止まらない。⚠ フレームが落ちるだけでエラーは出ない。**
→ ⚠ **`_apply_damage()` を再帰させないこと。⚠ 反射のダメージは専用の関数（`_apply_reflect()`）で作り、⚠ その中から反射の判定を呼ばない。**

### 2-2. ⚠ 軽減100%で決着しなくなる

⚠ **`amount` が必ず 0 になると、⚠ 誰も死なずに `180 秒たっても終わらないので諦める` の赤が出る。**
→ ⚠ **上限95%を定数で持つ**（§0-1 の8）。⚠ **データ側で上限を書けるようにしない。**

### 2-3. ⚠ 吸い切ったときに「0」を出さない

⚠ **シールドが全部吸うと `amount` が 0 になる。⚠ `results` にそのまま積むと、⚠ 頭上に緑でも赤でもない「0」が浮かぶ。**
→ ⚠ **`amount` が 0 の damage の1件は `results` に積まない。⚠ 代わりに `intervene` の `kind: "shield"` を出す**（何が起きたかはログに残る）。

### 2-4. ⚠ 畳むときに、古い平置きを黙って無視しない

⚠ **`intervene{}` へ移したあと、⚠ 古い平置きの `on_death` が残っていると、⚠ 今の実装は「知らない欄」の検出が無い（宿題11）ので無音で消える。**
→ ⚠ **平置きの3欄が書いてあったら赤にする（E102）。⚠ 移し忘れが必ず表面化する形にする。**

### 2-5. ⚠ `active` が偽の件を見ない

⚠ **既存の `_step_status_block()` / `_step_death()` / `heal_taken_pct` は全部 `active` を見ている**（`status_registry.gd:798-799`）。
→ ⚠ **新しい5つも同じ。⚠ 見落とすと、条件付きの軽減が偽の間に効く。**

### 2-6. ⚠ 編集したら `grep` で当たったことを確認する

⚠ **`grep -n "intervene" scripts/systems/skill_schema.gd` が0件でないことを、書いた直後に確認する。**

## 3. 実装（ファイル別）

⚠ **インデントはタブ。⚠ 関数を足す前に `grep -n "func <名前>"`。**

### 3-0. JSON の形（**決まり**）

```json
{
	"type": "buff",
	"host": "unit",
	"status_id": "st_dbg_shield",
	"duration_sec": 6.0,
	"intervene": {
		"shield_hp": 30,
		"reduction_pct": 40,
		"pierce_pct": 25,
		"crit_always": true,
		"reflect_pct": 50,
		"reflect_flat": 5,
		"on_death": { "revive_hp_ratio": 0.5 },
		"block_status": ["st_dbg_poison"],
		"heal_taken_pct": -50
	}
}
```

| 欄 | 型 | 誰の状態か | 意味 |
|---|---|---|---|
| `shield_hp` | int > 0 | ⚠ **殴られた側** | 肩代わりする量。⚠ **0になったら状態が消える** |
| `reduction_pct` | int 1〜95 | ⚠ **殴られた側** | 軽減%。⚠ **合計する。上限95** |
| `pierce_pct` | int 1〜100 | ⚠ **殴った側** | 相手の防御を無視する% |
| `crit_always` | bool | ⚠ **殴った側** | 確定クリティカル |
| `reflect_pct` | int > 0 | ⚠ **殴られた側** | 実際に減ったHPの何%を殴り返すか。⚠ **シールドが全部吸ったら 0** |
| `reflect_flat` | int > 0 | ⚠ **殴られた側** | ⚠ **殴られたら必ず返す固定値。⚠ シールドが全部吸っても返る**（人間の決定4） |
| `on_death` / `block_status` / `heal_taken_pct` | 既存 | — | ⚠ **中身は変えない。場所だけ移す** |

⚠ **9欄すべて省略可。⚠ 1つも無い `intervene{}` は赤（E103）。**

**足す関数（4本）**：

### 3-3. `scripts/systems/skill_resolver.gd`

**`_apply_damage()` の `ctx` に2つ足す**：

```gdscript
	"user": user,       # ⚠ 貫通・確定クリティカルが読む（殴った側）
	"target": target,   # ⚠ 軽減・シールド・反射が読む（殴られた側）
```

⚠ **`user_id` / `target_id` は消さない。**

**受け口の差し替え**：

```gdscript
	_step_crit_override(ctx, registry)
	_step_reduction(ctx, registry)

	ctx["amount"] = BattleFormula.damage(...)   # ← ここは1行も触らない

	# 【第2段】確定した数値を消費する。
	_step_shield(ctx, registry)                 # ⚠ take_damage() の前
	target.take_damage(int(ctx["amount"]))
	_apply_reflect(ctx, registry, results, is_dot)   # ⚠ take_damage() の後
```

**各 `_step_*` の中身**：

| 関数 | やること |
|---|---|
| `_step_crit_override(ctx, registry)` | ⚠ **`has_crit_always(user)` が真なら `ctx["is_crit"] = true`**。⚠ **`roll_crit()` の結果を上書きするだけ。乱数を振り直さない**（PLAN 11-2） |
| `_step_reduction(ctx, registry)` | ⚠ **貫通：`ctx["defense"] = defense * (100 - pierce) / 100`**。⚠ **軽減：`ctx["multiplier"] *= (100 - reduction) / 100`**。⚠ **順は貫通 → 軽減**（攻撃側を先に解決してから守備側） |
| `_step_shield(ctx, registry)` | ⚠ **`consume_shield(target, amount)` の戻り値を `ctx["amount"]` から引く。⚠ 吸った量を `ctx["shielded"]` に残す**（ログ用） |
| `_apply_reflect(ctx, registry, results, is_dot)` | ⚠ **`is_dot` なら何もしない**（§0-1 の4）。⚠ **`ctx["amount"]`（実際に減った量）× `reflect_pct` ＋ `reflect_flat` を攻撃者に `take_damage()`。⚠ 合計が 0 なら何もしない。⚠ `results` に1件積む。⚠ この中から反射の判定を呼ばない**（§2-1） |

⚠ **`amount` が 0 になったら `results` に damage の1件を積まない**（§2-3）。

### 3-4. `scripts/systems/battle_log.gd`
