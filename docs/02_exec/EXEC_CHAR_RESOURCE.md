## 2. 器（データ）

- ⚠ `characters.json` のキャラに `"resources": [...]`（⚠ 無いキャラは持たない＝いまの全員）
  ```json
  "resources": [
    {"id": "charge", "kind": "gauge", "max": 100, "start": 0, "name_key": "..."},
    {"id": "soul",   "kind": "stock", "max": 5,   "start": 0, "name_key": "..."},
    {"id": "stance", "kind": "state", "max": 1,   "start": 0, "name_key": "...",
     "labels": ["...", "..."]}
  ]
  ```
  - ⚠ `max` / `start` は数値（⚠ 読むとき `int()`・CLAUDE.md 3番）。⚠ `state` は `labels` の長さ＝`max + 1`
  - ⚠ 1キャラ最大2本（⚠ 下部パネルの枠の高さが決まっているため・⚠ 超えたらロード時の赤）
  - ⚠ **`carry_over`（bool・必須）**：⚠ `false` ＝戦闘ごとに `start` から ／ ⚠ `true` ＝**ランの中は持ち越す**（⚠ シナリオの通しも難ダンジョンも）
- ⚠ 値は戦闘の中だけ。⚠ 持ち越す資源だけ、ランの器 `RUN_RESOURCE_CARRY`（{character_id: {resource_id: int}}）に戦闘の終わりで書き戻す（⚠ ランを出たら器ごと消える・⚠ 拠点のセーブには残らない）
- ⚠ `BattleUnit.resources`（`{id: int}`）と `resource_defs`（マスターの写し・戦闘の間だけ）。⚠ 値を変えるのは `BattleUnit.add_resource()` / `set_resource()` の2本だけ（⚠ 0〜max に切る）

## 3. 増やす・使う（スキルの効果）

- ⚠ 効果の型 `resource` を1つ足す（`SkillSchema.EFFECT_RESOURCE`・⚠ 分岐は `SkillResolver.resolve()` の1か所）
  - `{"type": "resource", "resource_id": "soul", "amount": 1}` … 足す（⚠ 負なら減らす）
  - `{"type": "resource", "resource_id": "stance", "set_to": 1}` … その値にする（⚠ 状態の切り替え）
  - ⚠ 宛先は**撃った本人だけ**（⚠ 資源は持ち主のもの）。⚠ `host` は書けない
- ⚠ ロード時の検査（`SkillSchema`）：⚠ `amount` と `set_to` はどちらか1つ ／ ⚠ `resource_id` がそのスキルの持ち主の `resources` にある ／ ⚠ 種類が `state` なら `set_to`、それ以外は `amount`

## 11. 回CH-4：通常攻撃が変わる（2026-10-10）

> ⚠ 人間「⚠ １あ　２ひとによる　３あ」。⚠ 値は `BT-16`。

  ```json
  "basic_attack_every": {"every": 3, "attack": {"effects": [...]}}
  ```

- ⚠ 検証用：`char_debug_status` に 3回ごとの確定ダメージ・`skill_dbg_res_empower`（次の1回 ×5）・`skill_dbg_res_empower_timed`（3秒 ×2）
