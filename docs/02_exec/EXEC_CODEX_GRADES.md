## 2. ⚠⚠ いまの事実（**`grep` で取った・2026-09-28**）

| 事柄 | どこ |
|---|---|
| 図鑑の器 | ⚠ `CODEX: {item_id: {discovered, obtained_at}}`（`state_keys.gd:152`・`AGENTS.md:189`）。⚠ 等級は持っていない |
| 図鑑に載せる口 | ⚠ `_mark_codex_discovered()`（`game_manager.gd`）。⚠ 呼ぶのは `add_to_inventory()`（装備・持ち物）と `add_material()`（09-28 から） |
| 装備の等級 | ⚠ **品には無い**（`items.json` の装備11品に等級の欄は無い）。⚠ **個体が持つ**（`INSTANCE_GRADE`・1〜10） |
| 等級を書く所 | ⚠⚠ **2か所だけ**：⚠ `_create_equipment_instance()`（⚠ **必ず 1** で生まれる）／ ⚠ `forge_equipment_roll()` の成功（⚠ +1） |
| 値の式 | ⚠ `get_instance_stats_at_grade(instance_id, grade)` の中（⚠ 素の値 ＋ 素の値 × `GRADE_STAT_RATIO` ×（等級−1））。⚠ **個体が無いと引けない** |

⚠⚠ **いまの仕組みでは「等級 N を持ったことがある」なら 1〜N−1 も必ず持っていた**（⚠ 1で生まれ、1つずつ上がる）。
⚠ ＝⚠ 埋まる枠は「いちばん高かった等級まで全部」と同じ見え方になる。⚠ 差が出るのは**等級つきで生まれる装備（`EQ-13`・未実装）**が入ってから。
⚠ ＝⚠ **記録は「手に入れた等級の集まり」で持つ**（⚠ 最大だけにすると `EQ-13` で作り直しになる）。

## 4. 書き込む口（**1本に寄せる**）

- ⚠ 新しい口 `_mark_codex_grade(item_id, grade)`：⚠ 行が無ければ作り（⚠ `_mark_codex_discovered()` を通す）、⚠ `grades` に無ければ足して並べ直す
- ⚠ 呼ぶ所は**2か所**：⚠ `_create_equipment_instance()`（生まれた等級）／ ⚠ `forge_equipment_roll()` の成功（新しい等級）
- ⚠ 失敗・分解・捨てるでは**消さない**（⚠ 図鑑は「手に入れたことがある」の記録）
- ⚠ デバッグの「鍛冶の一式」も `forge_equipment()` を通る＝⚠ 同じ口で埋まる

## 5. 読み込み（**前のセーブ**）

- ⚠ `grades` の数を `int()` に戻す
- ⚠⚠ **前のセーブ（`grades` が無い装備の行）**：⚠ **いま持っている個体の等級から埋める**＝その個体の等級を N として 1〜N を足す（⚠ §2 のとおり、1で生まれて1つずつ上がったはず）
- ⚠ 手放した装備の等級は分からない＝⚠ 載らない（⚠ 素材の図鑑と同じ扱い・`NAV-13`）
