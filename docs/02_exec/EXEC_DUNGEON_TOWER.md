## 2. 方針（案）

### 2-1. 器は残し、網を「線」にする（⚠ 推し）

⚠ `DUNGEON_RUN` の `nodes` / `position` / `visited` と `move_in_dungeon()`・`clear_dungeon_battle()`・`clear_dungeon_boss()` は**そのまま使う**。
⚠ 変えるのは `_build_dungeon_map()` が組む形だけ：

```
ふつうの階：  戦 → 戦 → 戦 → 戦 → 主     （⚠ 5戦＝DG-3 の仮。⚠ 数は DungeonConfig の1つのつまみ）
特別な階  ：  商人   または   宝          （⚠ 1マスだけ・戦わない）
```

- ⚠ 主を倒す（特別な階はマスを済ませる）→ `phase = boss_cleared` → わかれ道の画面（上る／帰る）＝**今の流れのまま**
- ⚠ 理由：⚠ 地図・鞄・拾い待ち・戦闘のつなぎ・帰還報告書・`dungeon_sim` が全部この器の上に乗っている。⚠ 器ごと作り直すと、⚠ 動いている所まで巻き込む（CLAUDE.md 9番の事故の形）
- ⚠ 回D-道（シナリオ）は同じ「1本の線の並べ方」を `_build_floor_map()` で使い回す

### 2-2. 状態

| 鍵 | 変化 |
|---|---|
| ⚠ 最上位に **`dungeon_resume_floors`**（`{dungeon_id: int}`）を足す | ⚠ 「最後に帰った階」。⚠ 書くのは `retreat_from_dungeon()` だけ（⚠ 倒れた・降りたでは書かない＝`DG-3`「やはり最後に帰った階から」） |
| `DUNGEON_RUN` に **`floor_kind`**（`normal` / `merchant` / `treasure`） | ⚠ 階の種類。⚠ 画面の見出しと商人の棚の判定に使う |
| `DUNGEON_RUN_TORCH_GRADE` / `CORRIDOR_CHEST` / `RELICS` / `SHOP_SEEN` | ⚠ Q7・Q9 で消すなら外す（⚠ `load_state()` は知らない鍵を捨てる形にする） |
| `DUNGEON_BEST_FLOORS` | ⚠ 鍵も値もそのまま（⚠ 「ボスを倒した階の数」＝塔の「何階まで上った」） |

### 2-3. HP（`DG-3`「階の中だけ持ち越す」）

- ⚠ 階の中：⚠ 今の決定8 のまま（⚠ 戦闘の残り HP が次の戦闘の MAX HP）
- ⚠ 次の階へ上ったら：⚠ `_apply_dungeon_map()` で**素の MAX HP に戻す**（⚠ 倒れた人をどうするかは Q7）

### 2-4. 特別な階（`DG-3`「ランダム」）

- ⚠ 上るたびに抽選（⚠ 確率と続けて出るかは Q4）。⚠ 1階目（＝入った階）は必ずふつうの階
- ⚠ 商人：⚠ 今の `dungeon_shop` を開く（⚠ 棚は回復・蘇生・鞄+2。⚠ たいまつは外す）
- ⚠ 宝：⚠ Q5

### 2-5. 画面

- ⚠ 地図：⚠ 今の羊皮紙（`RunMapView`）に5マスを縦1本に並べる（⚠ 揺れ `RUN-16` は止める＝`RUN-17` の「線」）。⚠ Q1
- ⚠ 見出し：「12階　1 / 5 戦」（⚠ 「層」の字は消す・Q6）
- ⚠ 出撃の準備の縦図（`DepthGauge`）：⚠ Q2 で「選べない」なら「12階から」の1行に縮める
- ⚠ 帰還報告書：⚠ 「31 → 50 層」→「12 → 15 階」
