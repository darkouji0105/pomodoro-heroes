⚠ **`PartConfig` を新設する。⚠ `balance.gd` に `@export var part: PartConfig` を書いた瞬間、⚠ 未登録だと `Balance`（Autoload の1番）が Parse Error で落ち、⚠ ゲームが起動しない。**
⚠ **しかも `.tres` を割り当てる枠は、⚠ その `@export` を書かないと Inspector に現れない。**
→ ⚠ **実装を前半・後半に割る（§3-B-1）。⚠ 人間がエディタを開くのは2回・実作業は1回分。**
→ ⚠ **`Node` 型 ＋ `has_method()` で逃げない。⚠ `@export var part: Resource` にも落とさない**（`AGENTS.md`「エラーを理由にルールを緩めない」）。
⚠ **確かめ方**：`grep -c "PartConfig" .godot/global_script_class_cache.cfg`（⚠ **前半は 0 のまま／後半に入る前に 1以上**）。

### 2-2. ⚠ `.tres` をエディタ外でリネームすると `uid` が古いパスを指す

⚠ **`balance.tscn` の `ext_resource` に `uid` を書くと、⚠ Godot は `path` より `uid` を優先する。⚠ 前回それで `Parse Error: referenced non-existent resource` になった。**
→ ⚠ **`uid` を書かず `path` だけにする**（⚠ **`shop_config.tres` / `research_config.tres` / `workshop_config.tres` / `equipment_config.tres` の4つが既にこの形**）。

### 2-3. ⚠ `MasterDataLoader` が返す数値は必ず `float`

⚠ **`CLAUDE.md` 3番。⚠ `part_base` / `part_roll_max` / `part_tier` を `int()` で包み忘れると、⚠ ステータスに `+4.0` が出て、⚠ セーブにも `.0` が乗る。**

### 2-4. ⚠ 状態を変える前に全部の判定を終える

⚠ **`attach_part()` / `detach_part()` / `upgrade_part()` / `dismantle_part()` の4本とも `CLAUDE.md` 6番の形にする。⚠ `forge_equipment()` と同じく `# --- ここから状態を変える ---` の区切りを書き、⚠ 判定は全部その上に置く。**

### 2-5. ⚠ 再描画に `await` を持たせない ／ ⚠ モーダルの `await` は別物

- ⚠ **`_rebuild()` 系に `await` を入れない**（`AGENTS.md`）。⚠ **`remove_child()` → `queue_free()` の既存の形を崩さない**
- ⚠ **`Modal.confirm()` の `await` はボタンのハンドラに置く**（⚠ **`title_screen.gd:40` / `base_screen.gd:229` と同じ形。⚠ 実績はこの2本だけ**）。⚠ **`await` の間に別のシグナルで再描画が走ると、⚠ ハンドラを持っているノード自身が消える。⚠ 続きを書く前に `is_instance_valid(self)` を見る**

### 2-6. ⚠ ネストした Array は複製してから書き戻す

⚠ **`parts` は `equipment_instances.<id>.parts` の中の Array。⚠ 取り出して直接書き換えない**（`AGENTS.md`「状態アクセスのルール」）。
⚠ **`get_equipment_instance()` は `duplicate(true)` を返す**（`:1214`）ので、⚠ **そこから触って `_write_instance()` で戻す**（⚠ **`forge_equipment()` と同じ形**）。

### 2-7. ⚠ 「同じ形の判定」を2本目に書かない

⚠ **この回で1本にするもの**：

| 関数 | 何を1本にするか |

### 2-8. ⚠ 既に在る1本を使う（**2本目を書かない**）
