> ⚠ フロア4（31層〜）のスライムの HP が **40 → 52**（⚠ +10% × 3）、⚠ ボスの攻撃が **30 → 39** になるはず。

## 4. 作り方

- ⚠ **帯**：`dungeon.json` に `depth_bands`（`[{from_layer, battle_pool?, boss?, loot?}]`・⚠ 今は空）。⚠ 帯に書いた鍵だけが入口の表より優先（⚠ 書かない鍵は入口のまま＝同じ数字を2か所に書かない）
- ⚠ **引く口は1本**：`_dungeon_master_at(dungeon, key, layer)`＝⚠ `from_layer` が層以下の帯のうち一番深いもので、その鍵を持つもの → 無ければ入口の表
- ⚠ **層**：⚠ 敵はそのマスの層（`get_dungeon_absolute_layer(node.layer)`）・⚠ 戦利品はいま立っている層（`get_dungeon_current_layer()`）
- ⚠ **強さ**：`DungeonConfig.enemy_stat_growth_pct_per_floor`（仮 10）。⚠ 倍率＝`100 + 伸び × (floor_index − 1)`％（⚠ **入口から数えたフロア**＝31層から入っても強い）。⚠ 口は `get_dungeon_enemy_stat_pct()`。⚠ `get_dungeon_node_wave()` が HP・攻撃・防御を `stat_overrides` に書いて返す（⚠ 戦闘の側は触らない）
- ⚠ **宝箱の中身は入口の表のまま**（⚠ 拠点で開ける＝層が無い）。⚠ 帯で変えたくなったら、⚠ 宝箱の品を帯ごとに分ける（⚠ 別の回）
- ⚠ **見張り**：E133 を帯にも広げる（⚠ `from_layer` が 1 以上・昇順 ／ ⚠ 帯の `battle_pool` は空でない ／ ⚠ `boss` は Dictionary ／ ⚠ `loot` の ID が items.json に在る）
