## 4. 作り方

- ⚠ **鍵**：⚠ 等級つきの装備だけ `item_id#等級`（⚠ ほかは今までどおり `item_id`）。⚠ 組み立て `make_run_bag_key()`・読み解き `run_bag_item_id()` / `run_bag_grade()`・マス `make_run_item_entry()`（⚠ `SLOT_ENTRY_BAG_KEY` に鍵・`ITEM_ID` と `GRADE` に読み解いた値）。⚠ 画面はマスの鍵を返す（`run_entry_key()`）
- ⚠ **口の中で読み解く**：⚠ 重なる数（`get_run_bag_stack_limit()`）・品の名前（`item_name_key()`）・持ち帰り（`retreat_from_dungeon()` / `deliver_floor_bag()`）・報告書（⚠ 品の ID でまとめる）
- ⚠ **個体**：`add_to_inventory(item_id, count, item_type, grade := 1)` → `_create_equipment_instance(item_id, grade)`（⚠ 図鑑にもその等級）
- ⚠ **等級**：`dungeon.json` の `equip_grade`（⚠ `[下限, 上限]`・帯で上書きできる＝`DUNGEON_BAND_KEYS` に足す）。⚠ 口は `get_dungeon_equip_grade_range(dungeon_id, layer)`
- ⚠ **珍しい品**：`items.json` の `drop_min_grade`（⚠ 特殊効果の3品＝9・仮）。⚠ 抽選の前に、帯の上限に届かない品を表から外す ／ ⚠ 振る等級は `max(帯の下限, 品の最低)`〜帯の上限
- ⚠ **入口**：⚠ `_grant_dungeon_node_gains()` で装備が出たら、⚠ 1個ずつ等級を振って鍵にして拾い待ちへ
- ⚠ **表**：⚠ ボスの戦利品に装備を足す（⚠ 11品＝重み 2・特殊効果3品＝重み 1・仮）／ ⚠ `chests.json` の装備の行を消す
- ⚠ **画面**：⚠ 潜る深さの紙に「出る装備 等級◯以上」 ／ ⚠ 鞄・拾い待ちのマスに等級（⚠ マスの部品が等級を出せるか見る）
