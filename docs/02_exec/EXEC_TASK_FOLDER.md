## 0. 決まったこと

| # | 裁き | 中身 |
|---|---|---|
| 1 | あ | ⚠ フォルダとタグは両方残す。⚠ フォルダは1タスクに1つ（入れ物）・タグは複数の印のまま（`TK-12`） |
| 2 | あ | ⚠ 入れ子は無し（1段） |

| 6 | い | ⚠ フォルダを消すと中のタスクも消す（⚠ 確かめの窓・赤）。⚠ 消したタスクは記録に残らない（`TK-15` と同じ） |

## 1. 器

- ⚠ 状態 `TASK_FOLDERS`＝`[{folder_id, name, collapsed}]`（⚠ 並び＝作った順）／ `NEXT_TASK_FOLDER_ID`
- ⚠ タスクの欄 `folder`（⚠ "" ＝フォルダなし）。⚠ 記録（`TASK_LOG`）には持たせない
- ⚠ 前のセーブ：⚠ 全部「フォルダなし」・フォルダは空。⚠ 一覧に無いフォルダを指すタスクは「フォルダなし」へ

## 2. 口（`GameManager`）

- `get_task_folders()` ／ `add_task_folder(name)` ／ `rename_task_folder()` ／ `delete_task_folder()`（⚠ 中のタスクも）
- `set_task_folder(task_id, folder_id)` ／ `set_task_folder_collapsed()` ／ `is_task_folder_collapsed()`
- `get_task_groups(tasks)`：⚠ 画面が並べる順の組（フォルダの順 → 最後にフォルダなし）。⚠ 3つの画面が同じ口を使う
- `move_task()`：⚠ 同じフォルダの中の隣と入れ替える
- `add_task(title, folder_id = "")`

## 3. 画面

- ⚠ 見出しの行の部品 `TaskFolderHeader`（⚠ ▼／▶・名前・件数・押すと畳む）＝⚠ 3つの画面で使う＝ components
- ⚠ タスクの画面：⚠ 見出しに「名前を変える」「消す」・⚠ 一番下に「フォルダを作る」
- ⚠ 「詳しく」（`TaskDetailPanel`）に「フォルダ ▼」

## 4. 完了条件（`ui_flow`）

1. フォルダを作るとタスクの画面に見出しが出る・タスクを「詳しく」で入れるとその下に並ぶ
2. 見出しを押すと畳める・畳んだことが拠点の紙とポモドーロのサイドバーにも効く
3. フォルダなしは一番下
4. ▲▼は同じフォルダの中で動く
5. フォルダを消すと中のタスクも消える（確かめの窓）
6. 前のセーブ（`folder` の無いタスク）を読むと全部フォルダなし
