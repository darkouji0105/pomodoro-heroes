## 5. 作り方

### 5-1. 数え方（⚠ 用語）

- ⚠ **フロア**＝マップ1枚＝**10層**（⚠ 9層＋ボスの層）。⚠ `floor_index` は**入口から数えた番号**（1〜50）
- ⚠ **出口**＝フロアのボスの後（⚠ わかれ道）。⚠ 出口の番号＝フロアの番号（⚠ 出口4＝40層）
- ⚠ **層（表示）**＝`(floor_index − 1) × 1フロアの層 ＋ ノードの layer`。⚠ **計算する口は GameManager の1本**（`get_dungeon_absolute_layer(layer)`）。⚠ 画面で掛け算しない
- ⚠ 1フロアの層＝`dungeon.json` の `layers` の数 ＋ 1（ボス）。⚠ 口は `get_dungeon_layers_per_floor()`

### 5-2. マスターと Config

- ⚠ `dungeon.json` の `layers` を **9件**（⚠ 層1は入口の1マス・あとは3マス）。⚠ `_layers_note` を書き直す
- ⚠ `DungeonConfig`：⚠ `segment_count` **0** ／ ⚠ `max_floors` **50** ／ ⚠ `layer_weight_*` を **9本**（⚠ 25本の先頭9本）。⚠ **`.tres` は触らない**（⚠ 上書きが無いので `.gd` の既定値で効く）
- ⚠ 区画のコードは**消さない**（⚠ `segment_count` を戻せば戻る＝決定38 と同じ流儀）

### 5-3. セーブ（⚠ 器が変わる）

- ⚠ `DUNGEON_RUN` に **`start_floor_index`**（`GameStateKeys.DUNGEON_RUN_START_FLOOR`）＝⚠ 入ったフロアの番号。⚠ `_empty_dungeon_run()` に足す・⚠ 読み込みで `int()` に戻す
- ⚠ 前のセーブの進行中のランは鍵が無い＝⚠ **1 として読む**（⚠ そのランはフロア1から入ったので正しい）。⚠ 25層のマップはそのまま続く（⚠ 次のフロアから10層）
- ⚠ `DUNGEON_BEST_FLOORS`：⚠ **鍵も型も変えない**。⚠ 意味を「⚠ 入口から数えて、⚠ ボスを倒したいちばん深いフロアの番号」に読み替える（⚠ 前の値は「フロア1から倒した数」＝同じ数＝「5あ」）
- ⚠ 書く口は今のまま（`_update_dungeon_best()`・⚠ ランが終わる3つの口）。⚠ `_cleared_dungeon_floors()` は `floor_index` が入口からの番号になるのでそのまま正しい（⚠ 31層から入って40層の前で倒れたら 3＝更新しない）

### 5-4. 入る口

- ⚠ `get_dungeon_start_floor_options(dungeon_id)` → `[1, 2, …, min(最深 + 1, max_floors)]`（⚠ 判定の唯一の口）
- ⚠ `start_dungeon_run(dungeon_id, start_floor := 1)`：⚠ 選べない深さは弾く（⚠ 状態を触る前）
- ⚠ `enter_dungeon_with_ticket(dungeon_id, start_floor := 1)`：⚠ 深さの判定も札を減らす**前**に（⚠ CLAUDE.md 6番）
- ⚠ 通貨の伸び＝`floor_index − start_floor_index`（⚠ 「3あ」）

### 5-5. 画面

| 画面 | 何を出すか |
|---|---|
| ⚠ **出撃の準備**（難ダンジョン・新しく入るとき） | ⚠ 右の欄の上に紙「潜る深さ」（⚠ 「10層ごと」）：⚠ 坑道の縦図（`DepthGauge`・10層ごとの目盛り・開いた出口に印・選んだ所につまみ）／ ⚠ 大きく「31 層から」・「次の出口 40層」・「持ち込みなし」／ ⚠ 「−10」「+10」「最深へ」（⚠ 端は押せない）。⚠ 控えの紙はその下（⚠ 一覧はスクロール）。⚠ 「出撃する」で選んだ深さから入る。⚠ **続きからは出さない** |
| ⚠ **マップ** | ⚠ 見出し「フロア n/3」→「**31–40層**」・⚠ 目盛りは入口からの層 |
| ⚠ **戦闘** | ⚠ 見出しの層は入口からの層 |
| ⚠ **わかれ道** | ⚠ 見出し「**40層　ボスを倒した**」／ ⚠ 左「出る」／ ⚠ 右「**もう10層**」・「**41–50層**」。⚠ 500層では右のカードを出さない |
| ⚠ **ショップ** | ⚠ 「**41層へ**」 |
| ⚠ **報告書** | ⚠ 大きく「**31 → 50**層」・「50層の出口から出た」相当（⚠ 終わり方の一言は今のまま）／ ⚠ ボスの行「40層」／ ⚠ 最深「最深 50層」 |

- ⚠ 報告書に **`start_floor`**（`REPORT_START_FLOOR`）を足す（⚠ メモリだけ・セーブしない）
- ⚠ 値（縦図の大きさ・色・大きな数字）は `theme_builder.gd`（`DEPTH_GAUGE*`）。⚠ `theme_override_` は書かない
