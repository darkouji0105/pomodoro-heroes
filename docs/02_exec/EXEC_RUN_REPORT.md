## 4. 報告の中身（**セーブしない・メモリだけ**）

- ⚠ GameManager が**最後に終わったランの報告**を1つ持つ（`get_last_run_report()`）。⚠ 画面はこれを読むだけ
- ⚠ 中身：⚠ 種類（難ダンジョン／通常の依頼）・⚠ 終わり方（持ち帰り／倒れた／降りた）・⚠ ダンジョンか話のID・⚠ ボスを倒したフロアの数・⚠ 最深を更新したか・⚠ 持ち帰った品／消えたラン専用の品／満杯で置いてきた品／失った品（`{item_id: 個数}`）
- ⚠ **書く所**：⚠ `retreat_from_dungeon()`（持ち帰り）／ ⚠ `abandon_dungeon_run(reason)`（⚠ 倒れた＝`apply_dungeon_battle_result()` から ／ 降りた＝マップのメニューから）／ ⚠ `deliver_floor_bag()`（通常の依頼のクリア）
- ⚠ ボスを倒したフロアの数：⚠ 持ち帰り＝今のフロア ／ ⚠ 倒れた・降りた＝今のフロアのボスを倒していれば今のフロア・⚠ まだなら1つ前（`can_retreat_from_dungeon()` で見る）
- ⚠ **最深の更新は3つの終わり方ぜんぶで見る**（⚠ 倒れてもそこまで潜った事実は残る）
- ⚠ 起動し直すと報告は消える（⚠ 見ずに閉じたら見られない＝セーブに残さない）
