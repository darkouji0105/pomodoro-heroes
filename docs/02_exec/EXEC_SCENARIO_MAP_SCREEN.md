## 1. ⚠ 先に決めたこと（**設計役の決め**）

### 1-1. ⚠ スタミナは**ボスを倒したときに1回だけ**払う

⚠ **14-a の指示書に「いま払っているのは `adventure_select`」と書いたのは誤り。⚠ 実際は戦闘画面の `_consume_stage_stamina()` が**勝ったときだけ**払っている**（`battle_controller.gd:1643`）。⚠ **`adventure_select` は残量を確認しているだけ**（`:279`）。

⚠ **フロアでは、⚠ 道中の戦闘ノードでは払わず、⚠ ボスを倒したときに1回だけ払う。**
⚠ **理由：⚠ 既存のルール「勝ったときだけ・1周5スタミナ」をそのまま保てる。⚠ ノードごとに払うと1周25になる。**

### 1-2. ⚠ 固定報酬とクリア記録も**ボスだけ**

⚠ **フロアの `rewards`（ゴールドと素材）は「1周で入るもの」なので、⚠ ボス撃破で1回だけ配る。**
⚠ **`mark_stage_cleared()` もボスだけ。⚠ 道中のノードで呼ぶと1マス目で画面が全部開く。**

### 1-3. ⚠ 1ノード＝**1ウェーブ**

⚠ **フロアには `waves` が無い。⚠ ノードに入るたびに `battle_pool` から1本引いて1ウェーブの戦闘にする。⚠ ボスは `boss` をそのまま1ウェーブに。**
⚠ **1フロア5層＝道中の戦闘は最大4回＋ボス1回。⚠ 以前の「1ステージ5ウェーブ」と同じ量になる。**
⚠ **ただし戦闘以外のノード（休憩・レリック・ショップ）を踏むぶんだけ戦闘は減る。⚠ 数値の調整は後回し**（`PLAN_SCENARIO_MAP.md` §10-2）。

### 1-4. ⚠ HPはフロア内で持ち越す

- ⚠ **戦闘に勝ったら、⚠ 生き残った味方の残HPを `hp_carry` に書く**
- ⚠ **次の戦闘は `hp_carry` があればそのHPで始まる**
- ⚠ **倒れた味方は次の戦闘で **1** で復帰する**（⚠ **0 にすると復帰できない。⚠ 全滅の判定と噛み合わない**）
- ⚠ **休憩ノードで全員が満タンに戻る**（⚠ **まずはシンプルに＝メモの「様子見」**）
- ⚠ **フロアを降りると消える**（`abandon_floor()`）

### 1-5. ⚠ 負けたらフロアを降りる

⚠ **「負けてもノーリスク・何度でもやり直せる」＝⚠ フロアの最初からやり直し。**
⚠ **戦闘画面の「もう一度」はそのノードの再戦。⚠ 「戻る」でフロアを降りる。**
⚠ **スタミナは払っていないので返却も要らない**（§1-1）。

### 1-6. ⚠ レリックとショップのノードは**通過するだけ**

⚠ **踏んでも何も起きず、⚠ 「まだ作っていない」旨のメッセージを出して先へ進める。**
⚠ **⚠ 行き止まりにしないこと。⚠ 踏むと詰むノードがあるとフロアがクリアできない。**

## 2. マップ画面（`floor_map.tscn`）

- ⚠ **層を縦に並べる。⚠ 下が入口・上がボス**
- ⚠ **1層＝`HBoxContainer` 1本。⚠ 全体は `VBoxContainer`**
- ⚠ **`ScrollContainer` を使わない**（⚠ **中は `scenario=layout` で測れない。⚠ 5層なら 720px に収まる**）
- ⚠ **マスは `PrimaryButton`。⚠ 進める先だけ押せる。⚠ それ以外は `disabled`**
- ⚠ **いまいるマスと踏破済みのマスが見て分かること**
- ⚠ **ヘッダにフロア名・スタミナ・出た宝箱の数**
- ⚠ **フッタに「拠点へ戻る」**（⚠ **フロアは降りない。⚠ 続きから再開できる＝状態に残っている**）
- ⚠ **再描画に `await` を持たせない。⚠ `remove_child()` してから `queue_free()`**（`AGENTS.md`）
- ⚠ **`GameManager.floor_run_changed` を購読する**（⚠ **14-a で足した。⚠ いま購読者ゼロ**）
