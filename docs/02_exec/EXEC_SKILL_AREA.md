## 2. ⚠ 事故りやすい箇所

### 2-1. ⚠ `select` の挙動を1ミリも変えないこと（**この回で一番あり得る事故**）

絞り順を組み替えるので、**既存の `mode: select` のスキル全件が影響を受ける。**
⚠ **`sort: all` ／ `count` ／ `range` ／ `team: self` ／ `team: source` の5つは今までどおり動くこと**（§5-1 / §7）。

> **段階1の「挙動が1件も変わらない」（PLAN 17-1）と同じ完了条件を、この回も `select` に対して掛ける。**

### 2-2. ⚠ ユニットは動く。**しかも落ち着き先は「攻撃射程の差」で決まる**（2026-08-17・実装中に判明）

`_step_unit()`（`battle_controller.gd:601-627`）は **`距離 <= attack_range` になった瞬間に止まる。** つまり全員が**射程ぴったりの位置に停まる。**

⚠ **狙う相手は「一番近い相手」で、しかも生きている限り変えない**（`battle_controller.gd:568-589`）。
⚠ **その結果、同じ射程のユニットは全員ほぼ同じ x に重なる。** 味方3体は1箇所に積み上がる。

⚠ **さらに、`range` は `attack_range` 未満だと赤になる**（`master_data_loader.gd:592`。「移動AIが `attack_range` で止まるので永久に撃てない」）。**`char_debug_*` の `attack_range` は 300 なので、検証用スキルの `range` は 300 未満にできない。**

→ ⚠ **`range` の検証は「敵を動かさない」ことで成立させる。** `stat_overrides` は `spd` も上書きできる（`battle_controller.gd:307`）ので、**遠い群を `spd: 0` で置物にする。**

| | 落ち着く位置 | 根拠 |
|---|---|---|
| `enemy_dbg_ranged` ×2（⚠ **`spd: 0`**） | **900 / 1000（動かない）** | 湧いた場所のまま |
| 味方3体（射程 300） | **約 600** | 3体とも `900` の敵を狙い、300 手前で止まる。⚠ **狙う相手は死ぬまで変えない**ので、あとから狼が近づいても止まったまま |
| `enemy_wolf` ×2（射程 **50**） | **約 650** | 味方の手前まで詰める |

⚠ **これで「使用者から 300 / 400 の位置に敵が居る」が確定する。** `range: 300` では **`1000` の敵に届かない**のに、`radius: 450` の巻き込みには入る＝決定2が測れる。

⚠ **それでも「狼が歩いている途中」は件数が違う。完了条件は「狼が止まってから撃つ」を前提に書いてある。**

### 2-3. ⚠ `origin: "target"` の「起点」と「巻き込み」で母集団が違う

| | どの母集団から | なぜ |
|---|---|---|
| **起点を1体選ぶ** | ⚠ **`range` で絞ったほう** | 射程外の敵を起点にできてはいけない |
| **巻き込む** | ⚠ **`range` で絞る前のほう** | 決定2 |

⚠ **同じ `pool` 変数を使い回すと、必ずどちらかが間違う。名前を分けること。**

### 2-4. ⚠ `count` を赤にするのは `mode` を見たあと

`count` の検証は今 `else`（＝`select`）の枝にある（`skill_schema.gd:492-495`）。
⚠ **`area` の枝に「`count` があったら赤」を足す。** `select` 側の E13 は1文字も変えない。

### 2-5. ⚠ `radius` は「使用者からの距離」ではない

**中心からの距離。** ⚠ `range`（使用者からの距離）と混ぜないこと。名前が似ている。

### 2-6. ⚠ 死者は母集団に入らない

`session.get_alive_units(team)`（`skill_resolver.gd:89`）。⚠ **`radius` の中に死体があっても巻き込まない。今までどおり。**

### 2-7. ⚠ 効果ごとの `target` 上書きにも `area` が書ける

`_validate_target(..., allow_range: false)`（`skill_schema.gd:640`）が効果の中の `target` を同じ関数で検証している。
⚠ **`origin` / `radius` の検証もそこを自動的に通る。** 別の検証を書かないこと。
