## 2. 状態

`GOAL`（`"goal"`）＝ `{}`（目標なし）か

```
{lines: {item_id: 届けたい所持数 int}, origin: "item" | "recipe" | "level", ref: String, value: int, set_at: String}
```

- ⚠ 目標は「**所持数がその数に届く**」（⚠ 増やす数ではない）。⚠ 届いたら自分で消え、知らせが出る
- ⚠ `origin` / `ref` / `value` は見出しを作るためと、回AUTO-3 が「届いたあとに本来の操作をする」ための控え（⚠ item＝品・recipe＝レシピ・level＝キャラと目標の Lv）
