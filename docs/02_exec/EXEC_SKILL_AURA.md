## 3. 実装（ファイル別）

### 3-0. JSON の形（**決まり**）

```json
{
	"type": "buff",
	"host": "point",
	"status_id": "st_dbg_aura_atk",
	"duration_sec": 10.0,
	"zone": { "radius": 200.0, "team": "ally", "follow": true },
	"stat": "atk",
	"value": 10
}
```

| 欄 | 型 | 必須 | 意味 |
|---|---|---|---|
| `radius` | float > 0 | ✅ | 中心からの距離。⚠ **1次元（`absf(x - host_x)`）** |
| `team` | `ally` / `enemy` / `all` | ✅ | ⚠ **付与者から見て。⚠ 既定値を作らない** |
| `follow` | bool | ✅ | ⚠ **true＝付与者に追従。⚠ 付与者が死んだら最後の位置で固定** |

⚠ **`zone{}` は `host: point` にしか書けない**（E108）。⚠ **`host: point` に `zone{}` が無いのも赤**（E109）。

**周期ダメージ／周期回復の書き方**（`type: dot`）：

```json
{
	"type": "dot", "host": "point", "status_id": "st_dbg_pool",
	"duration_sec": 10.0, "interval_sec": 1.0,
	"zone": { "radius": 150.0, "team": "enemy", "follow": false },
	"multiplier": 1.0, "attack_type": "true", "scale_from": "atk",
	"heals": false
}
```

⚠ **`heals: true` にすると同じ形で周期回復になる**（§0-1 の8）。⚠ **`attack_type` は `heals: true` のとき書けない**（回復は防御を見ない）。

**原因と直し方**：

⚠ **`entry["inside"]` の差分で出していたので、⚠ entry ごと消える経路（寿命切れ・置き換え・宿主の死亡・`clear_for_unit`・`clear_all`）では、⚠ leave を出す相手も一緒に消えていた。**

→ ⚠ **器全体で「今 誰がどの範囲の中に居るか」（`_zone_seen`・鍵は `instance_id|unit_id`）を1つ持ち、⚠ 毎フレームその差分で出す形にした。⚠ entry が消えれば鍵も消えるので、⚠ どの経路で消えても自動的に leave になる。**

**③ ⚠ さらにもう1段あった：`tick()` の先頭の早期 return**

⚠ **`if _entries.is_empty(): return` があるため、⚠ 最後の1件が消えたフレーム以降 `_eval_zones()` が一度も走らず、⚠ 最後の範囲だけ leave が出ないまま戦闘が終わっていた。**
→ ⚠ **空でも `_zone_seen` が残っていたら出し切ってから帰る形にした。⚠ 1件も無いときのコストは空判定1回。**
