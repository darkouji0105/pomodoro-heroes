# 見る回の手順

2026-10-11 作成。2026-10-19 に、画面の作り直し（回UI-1018 の7画面）と、前から残っている5件に合わせて書き直しました。見る中身の一覧は `HUMAN_CHECK.md` の「未確認」で、ここはその**やり方**を書いています。

## この回でやること

今回見るのは13件です。

- 作り直した7画面（#35〜#42）：持ち物・鍛冶場・育成・詰所・本部（机とギルドの街）・依頼掲示板・研究
- 前から残っている5件（#31〜#34・#2）

見るのは「目で見て分かるか・手応えがあるか・気づけるか」の3つだけです。

- **見なくてよいもの**：押したら何が起きるか・どこへ移るか・壊れていないか。設計役が `scenario=ui_flow`（675本）と画面の絵（117枚）で確かめ済みです
- **全部見なくてよい**：言われなかった項目は「問題なし」として扱います
- **時間の目安**：1件5分前後、全部で1時間ほど
- **用意するもの**：いつも遊んでいるゲーム（ふつうに起動してよい）と、メモを書く場所（このファイルに直接書いても構いません）

## 始める前の準備

準備は最初に1回だけです。

1. ゲームをいつもどおり起動して、本部まで進む
2. **[0] キー**でデバッグの窓を開く
3. 「★ 見る回の準備（一発）」を押す。資源・素材・消費品・研究・画面が全部そろい、全員が Lv20 になる（装備は配らない）
4. 続けて、デバッグの窓で次の3つを押す
	- 「装備 全種1個」：持ち物・鍛冶場・育成の装備を見るため
	- 「鍛冶の一式（等級5）」：鍛冶場で鍛えるため
	- 「宝箱 高レア」：本部の宝箱の札（数の赤い丸）を見るため
5. **研究（F）を見るときだけ**、その直前にデバッグの窓の「研究 全部閉じる」を押す。「見る回の準備」が研究を全部開いてしまうので、閉じてから見ます。研究を閉じるとレベル上限が下がりますが、見る回には影響ありません

遊んだあと、設計役が先に Godot を動かすと、遊んだときのログが押し出されて消えます。**終わったら先に一声**ください。

## 見る順番と1件ずつの手順

画面ごとに9つに分けました。どの順で見ても構いません。括弧の番号は `HUMAN_CHECK.md` の番号です。研究（F）だけは、上の準備の5を先に済ませてください。

### A. 本部（2件・#39 机・#40 ギルドの街）

下の帯の一番左「本部」が机、その右隣の「ギルド」が街です。

#### 机（#39）

1. 帯の「本部」を押す
2. 左の「今日の紙」を上から順に見る：今日の集中 → やること → 知らせ
3. やることの行の四角を1つ押す（終えたことになり、線が引かれて残る）。もう一度押すと戻る
4. 真ん中の下の3枚の札を見る：集中の砂時計（15・25・45・50分の札）／冒険／依頼掲示板
5. 右の札を見る：宝箱（右上の赤い丸の数）・育てる（顔が並ぶ）・研究・ほかの施設
6. 右上の3つのアイコン（セーブ・設定・タイトルへ）にマウスを乗せる

- [ ] 机を開いたとき、何から手を付ければよいか分かるか
- [ ] 真ん中の上が空いていて寂しくないか（「あ：空けたまま」で決めた所。何か置きたくなったら一言）
- [ ] やることの四角を押して終えたのが分かるか。今日終えたものが線を引いて残るのは邪魔でないか
- [ ] 宝箱の札の右上の赤い丸（数）が、箱の絵に重ならずに見えるか
- [ ] 右上のアイコン3つが何のボタンか分かるか（名前はマウスを乗せると出る）
- [ ] 「シナリオ」「UIテスト」のボタンが無くて困らないか（UIテストのページはデバッグの窓の「UIテストのページ」から開けます）

#### ギルドの街（#40）

1. 帯の「ギルド」を押す
2. 建物を見回す。大きい4つ（冒険の門・宝物庫・集中の塔・訓練場）と、小さい建物
3. 建物の下の小さい字（「依頼 4 つ」「昇級できる 18人」など）と、赤い栞を見る
4. 好きな建物を押してその画面へ行き、戻ってくる（本部に戻っても街のまま）

- [ ] どれが何の建物か分かるか（絵はまだ仮の形です）
- [ ] 大きい建物が「毎日すること」だと伝わるか
- [ ] 赤い栞と小さい字に気づけるか
- [ ] 編成の3人が建物の間を歩くのが邪魔でないか

### B. 依頼掲示板（1件・#41）

1. 帯の「冒険」を押す（本部の机の「掲示板を見る ›」からでもよい）
2. コルク板の紙を何枚か押して、右の紙の中身が変わるのを見る
3. まだ開いていない話（第2話など）の紙も押してみる
4. 右の紙の「この依頼で出撃」を押して出撃の準備へ行き、「戻る」で戻る
5. 上のタブで「高難度の依頼」に切り替えて、同じように見る

- [ ] 紙を押すと右に詳しく出る、という使い方にすぐ気づけるか
- [ ] 紙の左上の札（本編・練習・高難度）で種類が分かるか
- [ ] 右の紙の報酬・敵・出る人が読みやすいか
- [ ] 話のひとこと（「村の外れにスライムが増えた」など）は仮の文です。直したい文があれば一言

### C. 詰所（1件・#38）

1. 帯の「育成」→ 上の紙のタブの「詰所」
2. 枠の「✕ 外す」で1人外して空きにする。もう一度、右の名簿の札を押して入れる
3. 右の名簿の「並び」（Lv・戦力・名前）と「役割」（前衛・遠距離・回復…）を切り替える
4. 枠の中の「使うビルド」の行を押して切り替える
5. 「組む・着替える ›」でビルドと装備の窓を開き、名前を変える・スキルや装備の枠を押して右から選ぶ → 「ビルド◯に残して閉じる」
6. 下の「編成の控え」で、空きの枠を含む並びを「いまを残す」→「呼ぶ」→「消す」

- [ ] 名簿の札を押して、どの枠に入ったか分かるか
- [ ] 戦力の数字と役割の札が、選ぶ助けになるか（役割の振り分けに異論があれば一言）
- [ ] ビルドの窓の操作はすぐ効くので、閉じるときの3つのボタン（残さずに閉じる／別の番号に残す…／ビルド◯に残して閉じる）の違いが伝わるか
- [ ] 難ダンジョンの出撃の準備では、上の「潜る深さ」に押されて名簿の札が1段ほどしか見えない。狭くないか（冒険 → 高難度 → 難ダンジョン →「この依頼で出撃」で見られます）

### D. 育成（1件・#37）

1. 帯の「育成」→ キャラの一覧から1人選ぶ
2. 身上書の一番上の「◀ ▶」で人を切り替える
3. 身上書のスキル・装備のアイコンにマウスを乗せる（詳しい札が出る）。押すとそのタブへ
4. 「ステータスノード」のタブで「+」と「−」を押す
5. 「スキル」のタブで枠を押して、重なって開く一覧から選ぶ
6. 「装備」のタブで部位を押して、マス目の候補から着ける

- [ ] ◀ ▶ で人を切り替えるのが手間でないか（上の顔の列はやめました）
- [ ] アイコンに乗せると出る札が読みやすいか
- [ ] ステータスノードの暗いマスの「+5」と「−」が分かるか。「−」で1段戻るのに気づけるか
- [ ] スキルの一覧が重なって開くのが分かりやすいか

### E. 鍛冶場（1件・#36）

1. 帯の「育成」→ 紙のタブの「鍛冶場」
2. マス目から装備を1つ押す → 右の紙で成功率と素材を見て「鍛える」
3. 鍛えた結果の画面を最後まで見る。もう一度は途中で画面を押して飛ばす
4. 「失敗しない所まで鍛える」を押す
5. 一括分解：「等級◯以下」を選び、見積もりを見て分解する（確かめの窓が出ます）
6. 育成の装備のタブの「鍛える」から来て、題の横の「◯◯の装備から来た」と「育成に戻る」を見る

- [ ] 金床の演出と、成功／失敗の印が気持ちよいか。長すぎないか
- [ ] 押すと飛ばせることに気づけるか
- [ ] 等級の色と数（マスの左上）、★（右下）、着けている人の顔（右上）が見分けられるか
- [ ] 一括分解で、着けている物と★の物が外れているのが分かるか

### F. 研究（1件・#42）

先に、デバッグの窓の「研究 全部閉じる」を押してください。

1. 帯の「育成」→ 紙のタブの「研究」
2. コルク板の札を見る。板を横に送って右端の「完成の報酬」まで見る
3. 光っている札（赤い画鋲）を押す → 右の紙を見て「解放する」→ 札に赤い栞が付く → もう一度押すと消える
4. 素材が足りない札を押して、「あと◯足りない・入手先を見る ›」を見る
5. 右上の「開けるだけ開く」→ 確かめの窓 →「開く」。ボード1が全部開き、ボード2が開く
6. 右端の「完成の報酬」を押して「受け取る」
7. 上の「▶」でボード2へ移る
8. 「自動 オフ」を押す → 窓で分類と「素材を残す」を見て「自動をオンにする」
9. デバッグの窓の「素材 全種」で素材を足してから、帯の「本部」へ戻る（本部に着いたときに自動で開きます）。本部の研究の札と、帯の「育成」の栞を見る。研究の画面に戻って、開いた札の栞を見る

- [ ] 板を横に送るのがやりにくくないか（ボード1は札が横に9列並びます）
- [ ] 札の4つの姿（済み・いま開ける・素材が足りない・前の研究が先）が見分けられるか
- [ ] 糸（赤＝済み・黒＝次・点線＝まだ）で、どれを開くと次が開くか分かるか
- [ ] 赤い栞に気づけるか
- [ ] 自動で開いたことが、本部に戻ったときに分かるか（窓は出しません）
- [ ] 区切りの研究の印（「★ 中間」「★★ 最後」）を札から外しました。無くて困らないか
- [ ] 完成の報酬の中身は仮です（ボード1＝金300・宝石50・素材2種×20）。直したければ一言

### G. 持ち物（1件・#35）

1. 帯の「持ち物」
2. 装備・装飾・素材のタブで、「見せ方」のマス目｜行を切り替える。「並び」と「しぼる」も触る

4. 素材のマスを押して「使い道」と「使う所へ行く ›」を見る
5. 装飾のタブで「3つ合わせて上の等級にする」を試す
6. 装備のタブから一括分解を試す（E と同じ部品です）

- [ ] マス目と行、どちらが見やすいか（どちらを最初に出すかを決めたければ一言）
- [ ] マウスを乗せて出る札が、邪魔にならず読めるか
- [ ] 「だれが着けると」の比べ（上がる・下がる）が分かるか
- [ ] 装飾の「合わせる」と「素材で上げる」の2つの道が分かるか

### I. 高難度の遊び比べ（1件・#2・決める項目）

1. 「塔（試作）」：1階＝4戦＋主。上るたびに HP が戻る。帰ると次はその次の階から
2. 「ふつうに戦う（試作）」
3. 「難ダンジョン」（今の網の形）

- [ ] 3つのうち、どれが「シンプルで続けやすい」か
- [ ] 商人の階・宝の階（それぞれ20%）に気づけるか
- [ ] 網の形（難ダンジョン）を畳むか。畳むなら、レリック・罠・たいまつ・休憩の仕組みも消す

## 気づいたことの書き方

問題なければチェックを付けるだけ、気になったら一言書くだけで十分です。整理は設計役がします。

- **問題なし**：チェックを付ける（付け忘れても、何も言われなければ問題なしと扱います）
- **気になった**：その行の下に一言書くか、会話にそのまま書く
- **決めた**：「高難度は塔で」「持ち物は行を先に」のように一言

書き方の例（このくらいで十分です）

| 書き方 | 設計役がすること |
| --- | --- |
| 街の建物 どれがどれか分からない | 形や名札を変える案をあ／いで出す |
| 研究 横に送るのめんどう | 板を縮める・縦に並べるなどの案を出す |
| 机の真ん中に〇〇を置きたい | 置き方の案を出す |
| 鍛える演出 長い | 長さを変えて、もう一度見てもらう |

画面のスクショを撮ったら、会話に貼ってください。

## 終わったら

会話に「見た」と一言ください。そのあとは設計役が進めます。

1. このファイルのチェックとメモを読む（会話に書いた分も）
2. 遊んだときのログ（`godot.log`）を読む。貼る必要はありません（**読む前に設計役が Godot を動かさない**）
3. 気になったものだけを直す案をあ／いで出す。決めてもらってから直す
4. 何も言われなかった項目は「済み」として `HUMAN_CHECK.md` から畳む

直したものは、次の見る回でもう一度だけ確かめてもらいます。
