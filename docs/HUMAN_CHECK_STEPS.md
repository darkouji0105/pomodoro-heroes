# 見る回の手順

2026-10-11 作成・2026-10-17 に今回の見る回（#21〜#30）へ書き直し。見る中身は `HUMAN_CHECK.md` の「未確認」で、ここはその**やり方**だけを書く。

## この回でやること

今回見るのは、10-14〜10-17 に入れた10件（#21〜#30）と、前から保留している3件（#1・#2・#4）です。見るのは「目で見て分かるか・手応えがあるか・気づけるか」の3つだけです。

- **見なくてよいもの**：押したら何が起きるか・壊れていないか。設計役が `scenario=ui_flow`（570本）と `char_resource` で確かめ済みです
- **全部見なくてよい**：言われなかった項目は「問題なし」として扱います
- **時間の目安**：1件5分前後、全部で1時間ほど
- **用意するもの**：いつも遊んでいるゲーム（ふつうに起動してよい）と、メモを書く場所（このファイルに直接書いても構いません）

## 始める前の準備

準備は最初に1回だけです。

1. ゲームをいつもどおり起動して、拠点まで進む
2. **[0] キー**でデバッグの窓を開く
3. 「★ 見る回の準備（一発）」を押す。資源・素材・研究・画面が全部そろい、全員がスキルのそろう Lv20 になる（装備は配らない）
4. 戦闘を見るときは、「パーティに入れる」の行で見たいキャラを選んで 1枠目へ入れる
5. 冒険 → 検証用のタブ →「検証用・見る回（しっかり戦える）」で戦闘に入る
	- しっかり戦える：3ウェーブ。味方も削られるので、倒れる・起き上がるが見える。負けそうなら [H]
	- 殴られ役：HP 99999・攻撃 1 の4体。見た目だけをじっくり見たいとき

### 戦闘中に使うキー（[F3] で一覧が出ます）

| キー | 使いどころ |
| --- | --- |
| [H] | 味方全員を全回復。負けそうなときに続けて見る |
| [D] | 味方を1人倒す（3枠目から）。フェニックスの起き上がりを見るとき |
| [S] | スキルのクールダウンを全部戻す。同じスキルを何度も見たいとき |
| [1]〜[4] | 速さ 1・2・4・8 倍。待ち時間を飛ばすとき（**手応えを見るときは1倍に戻す**） |
| [G] | 見下ろしの床 ⇔ 直線（前の形）の切り替え |
| [V] | 勝ったことにして戦闘を終える |

遊んだあと、設計役が先に Godot を動かすと、遊んだときのログが押し出されて消えます。**終わったら先に一声**ください（10-16 に一度消してしまいました）。

## 見る順番と1件ずつの手順

場所ごとに5つに分けました。どの順で見ても構いません。括弧の番号は `HUMAN_CHECK.md` の番号です。

### A. タスク（2件・#26・#1）

タスクのドラッグは、**3つの画面で同じ動き**にしました（10-17）。

1. 拠点の「やること」の「ひらく」でタスクの画面を開き、タスクを3つ以上とフォルダを1つ作る
2. タスクの画面で、行をつまんで別の行の**上半分**・**下半分**に落とす。フォルダの箱（見出し・空いている所）にも落とす
3. 拠点の紙（「やること」の紙）でも同じことをする
4. ポモドーロの画面の右のサイドバーでも同じことをする（集中中でもよい）

#### ドラッグ（#26）

- [ ] つまむ・落とすの手触り（**落とす場所の目印は出ません**。どこに入るか分かるか）
- [ ] 上半分なら前・下半分なら後ろ、で思ったとおりの所に入るか
- [ ] 行を押して選ぶ（ポモドーロでは「いまのタスク」にする・拠点の紙ではタスクの画面を開く）のと、つまむのがぶつからないか
- [ ] 畳んだフォルダの見出しに落として中に入るのが分かるか
- 終えたタスクはつまめません（サイドバー）。タグで絞っているときもつまめません（タスクの画面）

#### フォルダ（#1・保留していた分）

- [ ] フォルダの中に入っている感じがするか（見出しが箱の上の帯・中のタスクは箱の中・畳むと見出しだけ）
- [ ] 箱の地・帯の濃さが重すぎないか

### B. ポモドーロ（2件・#21・#29）

集中を待つ時間を飛ばしたいときは、ポモドーロの画面の左上のデバッグの「このフェーズを終わらせる」を使ってください。

#### ポモドーロの設定（#29）

1. 集中を始める（加護の「◯で始める」→「はじめる」。10-16 に2回押す形へ戻しました）
2. 集中中に「ポモドーロの設定」を開き、集中の長さを変える
3. 休憩中にも開いてみる

- [ ] 集中の長さを変えても、**今の時計は変わらず次から効く**のが分かるか（変わらないので壊れたと思わないか）

#### 受け取りの窓（#21）

1. 集中を1本終え、振り返りを書いて、休憩中に「やめる」で拠点へ（休憩中は確認の窓を出しません）
2. 拠点で受け取りの窓が出る。宝箱も見たいときは、加護の分まで集中してから戻る

- [ ] 箱が光って開き、札が浮かぶまでの長さ（待たされる感じがしないか）
- [ ] 手に入れた実感があるか
- [ ] 演出の途中で窓の中を押すと飛ばせる。「押すと飛ばす」に気づけるか・飛ばした手応え
- [ ] 札の名前の折り返し（「スタミナポーショ／ン」）が気にならないか

### C. 戦闘（5件・#23・#24・#25・#27・#30）

#### 狂った神の使いのショットガン（#23）

1. 狂った神の使いを 1枠目に入れて「殴られ役」で戦う

- [ ] 撃つたびに前へ扇形が光るのに気づけるか（0.35秒・前にいる味方と敵の下に描きます）
- [ ] 範囲で当たっている手応え（扇の中の敵全員に数字が出ます）
- [ ] 近いほど強いのが分かるか（今は数字の大きさだけです）

#### バフ・デバフの札の残り時間（#24）

1. 生徒（毒・火傷）や狂った神の使い（聖なる炎）を入れて戦う

- [ ] 札が**上から暗くなっていく**残り時間に気づけるか（札そのものが小さい件は前からの #5）
- [ ] スキルのクールタイムと同じ感じに見えるか

#### 一瞬で移る動き（#25・前の #4 の「一瞬で移る」もここで見る）

1. 傭兵（突進）・拳銃使い・吸血鬼（蝙蝠）などを入れて戦う
2. 検証用（状態）のスキル枠に「一番近い敵へ突進して殴る」「敵の真ん中へ飛び込んで殴る」「後ろへ下がる」「敵全員を押し出す」を入れて戦う

- [ ] 滑る速さ（900px／秒）は速すぎ／遅すぎないか
- [ ] まだ一瞬に見える動きが残っていないか
- [ ] 押し出しの距離（120）は気持ちいいか（#4）
- [ ] スタンした敵が止まっているのが分かるか（赤い「気」のマス・#4）

#### ゾンビ（#27）

1. ネクロマンサーを入れる（準備で Lv20 になっているので、屍の継ぎ接ぎが使えます）
2. 死者の行進で下級ゾンビを3体以上にしてから、屍の継ぎ接ぎを使う

- [ ] 下級 👻 と上級 👹 を見分けられるか
- [ ] 下級が全部まとまって上級1体になったのが分かるか
- [ ] 強さ（まとめた1体ごとに +10%。**値は仮**）

#### フェニックスの起き上がり（#30）

1. フェニックスを 3枠目に入れ、[D] で倒す

- [ ] 起き上がるまでの3秒は長すぎ／短すぎないか

### D. 育成と冒険（2件・#28・#22）

#### スキルタブ（#28）

1. 育成 → キャラ（狂った神の使いなどパッシブのあるキャラ）→ スキルのタブを下まで送る

- [ ] 下まで送ると出る「通常攻撃」と「パッシブ（いつも効く）」の欄に気づけるか
- [ ] 通常攻撃の説明の文で、どう攻撃するか分かるか

#### 操作量を減らした所（#22）

1. シナリオの話を歩く（戦闘のあとの拾いもの）
2. 鍛冶場の「鍛える」で「失敗しない所まで鍛える」を押す
3. 育成のステータスノードで「振れるだけ」を押す

- [ ] 拾いものが全部鞄に入ったとき、窓が出ずに地図の上に1行（「鞄に◯個入れた」）だけ出る。それに気づけるか
- [ ] 「失敗しない所まで鍛える」「振れるだけ」で一気に上がって、物足りなくないか

### E. 高難度の遊び比べ（1件・#2・保留していた分）

これだけは「決める」項目です。冒険 → 高難度にある3枚を、それぞれ少しずつ遊びます。

1. 「塔（試作）」：1階＝4戦＋主。上るたびに HP が戻る。帰ると次はその次の階から（宝の階で宝箱を開けずに閉じても進めるよう、10-14 に直しました）
2. 「ふつうに戦う（試作）」
3. 「難ダンジョン」（今の網の形）

- [ ] 3つのうち、どれが「シンプルで続けやすい」か
- [ ] 商人の階・宝の階（それぞれ20%）に気づけるか
- [ ] 網の形（難ダンジョン）を畳むか。畳むなら、レリック・罠・たいまつ・休憩の仕組みも消す

### 数えない件（余裕があれば）

#3・#5 は、出ていることを設計役が絵で見ています。小さい・目立たない件だけ、直すかどうか一言ください。

## 気づいたことの書き方

問題なければチェックを付けるだけ、気になったら一言書くだけで十分です。整理は設計役がします。

- **問題なし**：チェックを付ける（付け忘れても、何も言われなければ問題なしと扱います）
- **気になった**：その行の下に一言書くか、会話にそのまま書く
- **決めた**：「高難度は塔で」「+10% でいい」のように一言

書き方の例（このくらいで十分です）

| 書き方 | 設計役がすること |
| --- | --- |
| 扇形 気づけない | 目立たせる案をあ／いで出す |
| 滑るの遅い | 速さを変えて、もう一度見てもらう列に戻す |
| ドラッグ どこに入るか分からない | 落とす場所の目印（線）を出す案を出す |
| 受け取りの演出 長い | 長さを変えて、もう一度見てもらう |

画面のスクショを撮ったら、会話に貼ってください。

## 終わったら

会話に「見た」と一言ください。そのあとは設計役が進めます。

1. このファイルのチェックとメモを読む（会話に書いた分も）
2. 遊んだときのログ（`godot.log`）を読む。貼る必要はありません（**読む前に設計役が Godot を動かさない**）
3. 気になったものだけを直す案をあ／いで出す。決めてもらってから直す
4. 何も言われなかった項目は「済み」として `HUMAN_CHECK.md` から畳む

直したものは、次の見る回でもう一度だけ確かめてもらいます。
