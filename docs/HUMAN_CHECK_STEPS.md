# 見る回の手順

2026-10-11 作成。見る中身は `HUMAN_CHECK.md` の「未確認」で、ここはその**やり方**だけを書く。

## この回でやること

今回見るのは、遊ばないと分からない12件です。見るのは「目で見て分かるか・手応えがあるか・気づけるか」の3つだけです。

- **見なくてよいもの**：壊れていないか（エラー・数字の異常・組み合わせのバグ）。945戦の総当たり（`scenario=soak`）で確認済みです
- **全部見なくてよい**：言われなかった項目は「問題なし」として扱います
- **時間の目安**：1件5分前後、全部で1時間ほど
- **用意するもの**：いつも遊んでいるゲーム（ふつうに起動してよい）と、メモを書く場所（このファイルに直接書いても構いません）

## 始める前の準備

戦闘の下のパネルは、各キャラの区画の上側に **HP（棒と数）** と **固有の資源（魂・血は丸、充電は棒と数）** が大きく出ます（2026-10-12）。

準備は最初に1回だけです。キャラを入れ替えるたびに、手順 4・5 だけを繰り返します。

1. ゲームをいつもどおり起動して、拠点まで進む
2. **[0] キー**でデバッグの窓を開く
3. 「★ 見る回の準備（一発）」を押す。資源・素材・研究・画面が全部そろい、全員がスキルのそろう Lv20 になる（装備は配らない）
4. 「パーティに入れる」の行で、見たいキャラを選んで 1枠目へ入れる
5. 「スキル枠 次の組へ」を押すたびに、枠のスキルが 1・2本目 → 3・4本目 → 5・6本目 と変わる。6本を見るには、押しては戦う、を3回繰り返す
6. 冒険 → 検証用のタブ →「検証用・見る回（しっかり戦える）」で戦闘に入る
	- しっかり戦える：3ウェーブ（スライムとオオカミ → 毒を付ける敵つき → スライムキング）。味方も削られるので、回復・起き上がり・解除が見える。負けそうなら [H]
	- 殴られ役：HP 99999・攻撃 1 の4体（ボスつき）。スキルの見た目だけをじっくり見たいとき

### 戦闘中に使うキー（[F3] で一覧が出ます）

| キー | 使いどころ |
| --- | --- |
| [H] | 味方全員を全回復。負けそうなときに続けて見る |
| [D] | 味方を1人倒す（3枠目から）。起き上がり・リザレクションを見るとき |
| [S] | スキルのクールダウンを全部戻す。同じスキルを何度も見たいとき |
| [1]〜[4] | 速さ 1・2・4・8 倍。待ち時間を飛ばすとき（手応えを見るときは1倍に戻す） |
| [V] | 勝ったことにして戦闘を終える |

遊んだあと、設計役が先に Godot を動かすと、遊んだときのログが押し出されて消えます。**終わったら先に一声**ください。

## 見る順番と1件ずつの手順

場所ごとに4つに分けました。A のキャラ9人が中心で、どの順で見ても構いません。括弧の番号は `HUMAN_CHECK.md` の番号です。

### A. キャラの戦闘（9件）

各キャラでやることは同じです。

1. 「パーティに入れる」でそのキャラを 1枠目に入れる
2. 戦闘に入り、スキル2本を何度か使う（[S] でクールダウンを戻すと早い）
3. 「スキル枠 次の組へ」を押して、もう一度戦う。これを全部で3回（6本）

動くかどうかは設計役が全部確かめ済みです（`HUMAN_CHECK.md` の「設計役が確かめたこと」）。ここに残したのは、目で見ないと分からないものだけです。

#### 学者（#6）

- [ ] 充電の溜まりにくさ（手応え）
- [ ] 帯電・再生（押すと入る・もう一度押すと切れる）が、入っているか切れたか分かるか
- [ ] 硬い役として前に立っている感じがするか

#### 吸血鬼（#11）

- [ ] 吸って回復しているのに気づけるか（緑の数字）
- [ ] 血の丸（10個）がたまるのに気づけるか（下のパネルの上側にも出ます）
- [ ] 蝙蝠で狙いの場所へ飛ぶのが変に見えないか

#### フェニックス（#12）

[D] で倒すと起き上がりをすぐ見られる。入れるのは 3枠目。

- [ ] 倒れて起き上がったのが分かるか
- [ ] オーバーヒートで自分が倒れるのが「失敗」に見えないか
- [ ] 顔の 🐦（青い小鳥）でよいか

#### 学者の生徒（#13）

- [ ] 分析が重なっていくのに気づけるか（「分」のマスが段の数だけ並ぶ）
- [ ] レーザー（0.2秒ごと）の数字がうるさくないか

#### 拳銃使い（#14）

- [ ] 跳弾を溜めている間の天井と跳ね返りの線が分かるか。弾が跳ね返って落ちるのが見えるか
- [ ] ナイフの残り回数がマスに出ていないが、困らないか
- [ ] 追い撃ち・はいぬーんの通常攻撃がうるさくないか

#### マグナムメイジ（#15）

- [ ] 魔印の爆発に気づけるか
- [ ] 弾幕の間「空中」なのが分かるか（飛ぶ演出は無い）
- [ ] 顔の 🔫（おもちゃの水鉄砲に見える）でよいか

#### 僧侶（#16）

リザレクションは [D] で味方を倒してから。

- [ ] リザレクションで起き上がったのが分かるか
- [ ] 祈りを押し直して、対象が移ったのが分かるか
- [ ] スキルのマスが文字（ヒ・招）でよいか

#### バイク（#17）

- [ ] 通常攻撃で走り抜ける速さ・気持ちよさ
- 引火の炎の跡は**画面に描かれていません**（効果は出ています）。見なくて構いません。描くかどうかは下の「見つかったもの」で決めてください

#### ボディビルダー（#18）

殴られるので 3枠目に入れると分かりやすい。

- [ ] パンプアップの緑の数字が3人から出るのに気づけるか
- [ ] スキルを使うたびに全員に付く「筋」のマスに気づけるか
- [ ] ポーズの絵がまだ無い（数字だけ）が、今はこれでよいか

### B. 検証用の状態スキル（1件・#4）

1. 「パーティに入れる」で「検証用（状態）」を入れる
2. 育成のスキル枠に「敵全員をスタン2秒」「敵全員を押し出す」を入れて戦う
3. 次に「一番近い敵へ突進して殴る」「敵の真ん中へ飛び込んで殴る」「後ろへ下がる」を入れて戦う

- [ ] 押し出しの距離（120）は気持ちいいか。短いか長いか
- [ ] スタンした敵が止まっているのが分かるか（赤い「気」のマス）
- [ ] 一瞬で移るのが変に見えないか。下がったあと止まる長さはちょうどよいか

### C. 高難度の遊び比べ（1件・#2）

これだけは「決める」項目です。冒険 → 高難度にある3枚を、それぞれ少しずつ遊びます。

1. 「塔（試作）」：1階＝4戦＋主。上るたびに HP が戻る。帰ると次はその次の階から
2. 「ふつうに戦う（試作）」
3. 「難ダンジョン」（今の網の形）

- [ ] 3つのうち、どれが「シンプルで続けやすい」か
- [ ] 商人の階・宝の階（それぞれ20%）に気づけるか
- [ ] 4戦＋主の長さはちょうどよいか
- [ ] 網の形（難ダンジョン）を畳むか。畳むなら、レリック・罠・たいまつ・休憩の仕組みも消す

### D. タスクのフォルダ（1件・#1）

タスクの画面、拠点の紙、ポモドーロのサイドバー（小窓のリストも）を開いて見ます。

- [ ] フォルダの中に入っている感じがするか（見出しが箱の上の帯・中のタスクは箱の中・畳むと見出しだけ）
- [ ] 箱の地・帯の濃さが重すぎないか
- [ ] 新しいタスクが「フォルダなし」に入るので困らないか

### E. 見下ろしの床（1件・#19）

戦闘中に [G] で「見下ろし ⇔ 直線（前の形）」を切り替えて比べます。近接の多いパーティ（剣士・傭兵・ボディビルダー）だと分かりやすいです。

- [ ] 重なりそうな近接が、歩いて奥か手前へずれる動きが自然か
- [ ] 足元の影で「床に立っている」感じがするか。傾きの強さ
- [ ] 見下ろしと直線のどちらにするか

### F. 見つかったものを決める

- [ ] 地面に置く範囲（炎の跡・骨の結界・スモッグの霧など）に絵が無い。床の上に楕円で描くか
- [ ] ナイフの残り回数をマスに出すか

### 数えない件（余裕があれば）

設計役が絵で見た #3・#5・#7〜#10 は、余裕があればで構いません。ただし、絵で「小さい」「重なって見える」と分かっているもの（ネクロの魂の丸・ゾンビが味方に重なるなど）は、直すかどうかだけ一言ください。詳しくは `HUMAN_CHECK.md` の「設計役が絵で見たこと」。

## 気づいたことの書き方

問題なければチェックを付けるだけ、気になったら一言書くだけで十分です。整理は設計役がします。

- **問題なし**：チェックを付ける（付け忘れても、何も言われなければ問題なしと扱います）
- **気になった**：その行の下に一言書くか、会話にそのまま書く
- **決めた**：「高難度は塔で」「顔はこのままでいい」のように一言

書き方の例（このくらいで十分です）

| 書き方 | 設計役がすること |
| --- | --- |
| パンプアップ 気づけない | 目立たせる案をあ／いで出す |
| レーザー うるさい | 数字をまとめるなどの案を出す |
| 押し出し もう少し長く | 値を変えて、もう一度見てもらう列に戻す |
| 顔の鳥 変えて | 候補の絵文字を並べて聞く |

画面のスクショを撮ったら、会話に貼ってください。

## 終わったら

会話に「見た」と一言ください。そのあとは設計役が進めます。

1. このファイルのチェックとメモを読む（会話に書いた分も）
2. 遊んだときのログ（`godot.log`）を読む。貼る必要はありません
3. 気になったものだけを直す案をあ／いで出す。決めてもらってから直す
4. 何も言われなかった項目は「済み」として `HUMAN_CHECK.md` から畳む

直したものは、次の見る回でもう一度だけ確かめてもらいます。
