# 画面の手直し（2026-10-18）— Claude Code に渡すメモ

`mocks/` の HTML が完成形。各 HTML の枠の下にある「見本の切り替え」で状態を見られる（Godot には作らない）。
共通の部品：**並べ替えの欄**（見せ方［マス目｜行］・並び・しぼる・★だけ）、**装備のマス**（左上＝等級の色と数、右下＝★、右上＝着けている人の顔）、**触れると出る詳しい札**、**確認の窓（モーダル）**、**一括分解の選び方**。持ち物・鍛冶場・育成・詰所で同じものを使う。

## 1. 詰所（Barracks.html）
- 左に3枠（前・中・後）、右に名簿（2列・縦スクロール）、下に編成の控え（8件・横一列）。
- 名簿を押す：出ていない人→空いている枠に入る／出ている人→外れる。枠の「✕ 外す」でも外せる。並びは各枠の「◀前へ／後ろへ▶」。
- 各枠に「使うビルド」1〜3を縦に並べ、押すとすぐ切り替え（名前＋スキル2・装備5のアイコン）。空き番号は「＋組む」。
- 「中身を直す・着替える」で**ビルドと装備の窓**：左＝ビルド1〜3（出撃で使う丸・ゴミ箱）とステータス10個、中＝スキル2枠・装備5枠・ルーン、右＝候補（装備はマス目、ほかの人の物は暗く）。下で「ビルド◯に残して閉じる」。
- 控え・ビルドを消すときは確認の窓。

## 2. 育成（Training.html）
- 上の顔の列を廃止。身上書の一番上に「◀ 前の人｜n / 18 人・一覧へ｜次の人 ▶」。
- 身上書にスキル2つ（枠つき）と装備5つのアイコン。触れると詳しい札、押すとそのタブへ。
- 概要：ステータスノードの振り方を小さな札で（＋5／4pt → ＋20）。装備アイコンも触れると札。「鍛冶場へ」。
- ステータスノード：暗いマスにアイコンと「+5」を大きく。−／＋／振れるだけ。残りptはタブに赤い数字。
- スキル：枠1・枠2をふちつきスロットに。押すと一覧が重なって開く（他の枠のスキルを選ぶと入れ替え）。
- 装備：部位5枠（着けている部位に「鍛える」→鍛冶場へその装備を選んで移る）。候補はマス目・並べ替えつき、ほかの人の物は暗く右上に顔、自分のは「着用中」。

## 3. 鍛冶場（Forge.html）
- 持っている装備を12列のマス目で（行にも切り替え）。並び＝いつもの順・等級・部位・名前、しぼる＝部位・等級・★・着けている物。
- 右：鍛冶の腕 Lv、いま→鍛えたら、成功率の印、素材、確定成功の札、「鍛える」「失敗しない所まで鍛える」。等級10は「遺物に捧げる」。
- 鍛えると結果の画面（金床の演出→成功／失敗の印）。**押すと飛ばせる**。「続けて鍛える」「閉じる」。
- 一括分解：等級◯以下をまとめて選ぶ、着けている物は選べない、★はまとめに入らない、確認の窓。
- 育成から来たときは題の横に「剣士の装備から来た」、戻るは「育成に戻る」。

## 4. 研究（Research.html）
- 研究室のコルク板。**1画面に1ボード固定**。ボードは左右の矢印と上の「◀［ボード2　2/6　進み］▶」で移る（タブはなし。上はいまのボードだけ）。
- 研究は画鋲で留めた札。済み＝黒＋封蝋「済」、いま開ける＝光る札＋赤い画鋲、素材不足＝ふつうの札（素材が赤）、前の研究が先＝点線。線＝赤い糸（済）／黒い紐（次）／点線（まだ）。札どうしは間を空けて矢印が見えるように。
- 各ボードの右端に「完成の報酬」の札（ほかの研究と同じ形）。押すと右に報酬一覧と「受け取る」。
- 閉じたボードも中身は見える（左上に「ボード1を8つ開くと開く」）。
- 「開けるだけ開く（確認の窓）」と「自動で研究（オン／オフ・分類ごと・素材を残す量）」。
- 研究が開いたとき（自分で・まとめて・自動）は窓を出さず、**赤い栞**で知らせる（ほかの知らせと同じ）：開いた札の左上・上のボード名・「研究」タブ・本部の研究の札。札を押すと消える。

## 5. 本部（Main.html）
- 机の画面：左＝今日の紙（今日の集中・やること・知らせ）、真ん中＝**上は空けておく**／下に細い札3枚（集中の砂時計・冒険・依頼掲示板）、右＝宝箱・育てる・研究の札とほかの施設。
- 依頼掲示板は別画面（コルク板に依頼の紙、右に詳しく、「この依頼で出撃」）。
- 下の施設の帯に「ギルド」を追加 → ギルドを見渡す街の画面（毎日する4つは大きい建物、知らせは赤い栞）。
- 右上はセーブ・設定・タイトルへのアイコンだけ。「シナリオ」「UIテスト」は外す。

## 6. 持ち物（Belongings.html）
- 装備・装飾・素材の全タブで［マス目｜行］の切り替えと並べ替え。装飾・素材はマスの右下に数（0は薄く）。
- 押すと右の紙に詳しく（装備：能力・★・装飾の枠・だれが着けるとの比べ・着ける／鍛える／分解）。
- 装備タブから一括分解（鍛冶場と同じ部品）。

- 研究の完了は赤い栞で知らせる。
