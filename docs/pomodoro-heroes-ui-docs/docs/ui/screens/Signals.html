決めごと
色は1つの意味だけ赤＝知らせ・危険・判、真鍮＝できる・選んでいる、墨と金＝特殊効果、ふちの色＝等級。ほかの意味に使い回さない
ステータスの名前身上書だけ名前を出す（覚える場所）。ほかはアイコン＋数字で、触れると名前
説明の窓があふれたら中身だけを送れるようにし、下の操作（着ける・鍛える・分解）はいつも見えるように固定
細かい数字ふだんは大きな数字だけ。「詳しく（Alt）」で伸び方や出どころを開く
小さい字の色紙の上の小さい字は #6E5A43 より濃く。使えないボタンだけは薄くてよい
画面の大きさ拡大しない。広くなった分だけ見える範囲を増やす（一覧の行・広間の奥行き）。見出しと下の帯は横いっぱい、説明の窓は幅を固定
