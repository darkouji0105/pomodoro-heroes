# コンセプトシート

## 一行コンセプト
ポモドーロ（作業時間管理）をこなすと報酬がもらえる、拠点育成×簡易戦闘のハイブリッドゲーム。

## 核となるループ（コアループ）
```
ポモドーロを実行
  → 完了で報酬（スタミナ／宝箱／ノルマトークン）獲得
  → 報酬を使って拠点・ギルド（育成・研究・作業場）を強化
  → 冒険選択画面でステージに挑戦（スタミナ消費）
  → 素材・経験値を獲得
  → また次のポモドーロへ
```

## 設計原則（最優先で守ること）
- **「ポモドーロをやったらご褒美」という約束を裏切らない**
- **プレイヤーに「やって後悔した」と思わせない**
- **頑張る楽しさを、素直に嬉しい手応えとして返す**

この原則は、報酬設計・ペナルティ設計で迷ったときの判断基準にする。
（例：ポモドーロを中断しても報酬をゼロにせず、経過時間に応じた部分報酬にする、という判断はこの原則に基づく）

## ジャンル
時間管理 × 育成/放置 × 簡易戦闘

## プレイヤーができること
- ポモドーロ（作業タイマー）の実行
- 拠点の施設拡張・キャラクター鑑賞
- ギルドでの育成（スキル選択・レベル上げ・装備）・研究・作業場でのクラフト
- ショップでの日替わり／週替わり／月替わり購入
- 冒険選択画面からストーリーステージ・トレーニングモードへの挑戦

## 勝利条件・進行の軸
- シナリオ進行がメインの進行軸（詳細は今後のシナリオ設計で確定）
- 明確な「勝利/敗北」よりも、継続的な育成・進行が主体

## 対象プラットフォーム
**PCのみ（Steam前提）。** 理由は`GAME_DESIGN.md` 1章。

## 想定プレイ時間
1プレイ＝1ポモドーロサイクル（作業時間プリセットに準拠：15分〜50分程度）
