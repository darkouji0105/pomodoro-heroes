## 拠点画面
- [ ] 上部ウィンドウに施設・キャラクターが描画される

- [ ] 建築素材を消費して施設を建設・配置できる
- [ ] 下部ウィンドウに gold / stamina（現在値/最大値） / 建築素材が常時表示される
- [ ] 冒険・ギルド・ポモドーロ・設定・シナリオへの遷移ボタンが機能する

## 冒険選択画面
- [ ] ストーリーステージ・トレーニングモードへの遷移ボタンがある
- [ ] ストーリーステージ1〜10面が選択できる
- [ ] ステージ選択後、パーティ選択画面に遷移する
- [ ] パーティ選択後、戦闘画面に遷移する
- [ ] 戦闘画面：パーティが自動で敵に接近し、間合い内で自動攻撃する
- [ ] 戦闘画面：スキルボタンでスキルを手動発動できる（クールダウン制）
- [ ] 戦闘画面：1ステージ5ウェーブ構成で、ウェーブ間はHP・バフを引き継いで連戦になる
- [ ] 戦闘画面：最終ウェーブにボス（強化ステータス敵）が出現する
- [ ] 戦闘画面：勝敗判定後、結果画面（Stage Clear / Defeated）に遷移する
- [ ] ステージクリアで資材が獲得できる（経験値ではなく、レベルアップ用素材のドロップとして獲得する）
- [ ] トレーニングモードで敵ダミーを攻撃し、ダメージ/DPSが確認できる
- [ ] （ダンジョン・戦闘プレビュー・ボスはボタンごと非表示、または実装しない）

## ポモドーロ
- [ ] 加護（ライト／ミドル／ハード）を1日1回選択できる
- [ ] 作業タイマーがプリセット（15/3・25/5・50/10）ごとに動作する
- [ ] セット数・長休憩の分数・長休憩の挿入間隔をユーザーが範囲内で設定できる
- [ ] 作業終了後、自動で振り返り入力画面に遷移する
- [ ] 20文字以上入力すると確定ボタンが有効化される
- [ ] 120秒以内に確定しなかった場合、未入力扱い（そのセットはノーカウント）になる
- [ ] 休憩がバックグラウンドで自動開始する
- [ ] 振り返り完了後、休憩をスキップできる
- [ ] 一時停止・再開ができる
- [ ] アプリを閉じてから5分以内に再開すると状態が復元される
- [ ] 5分を超えると中断セッションとして確定し、stamina加算・加護しきい値には反映されるが、履歴には残らない
- [ ] 加護のしきい値到達で報酬倍率が正しく適用される
- [ ] 加護選択の「1日1回」判定が毎朝4:00基準で行われる（ストリーク判定と同じ基準）
- [ ] ストリークが正しくカウントされる（4:00基準の日付切り替え）
- [ ] 猶予日数が消費・リセットされる
- [ ] 猶予日数を超えた場合、防衛チケットが自動消費される
- [ ] 防衛チケットが7・14・21日達成で獲得できる
- [ ] 記録画面で過去のセッション履歴が閲覧できる
- [ ] 建築素材を消費してタイマー装飾を購入・装備できる
- [ ] 作業開始前にセッションタイトルを任意で入力でき、2セット目以降は前セットの値が初期値になる
- [ ] 設定画面でRich Presence表示のオン/オフが切り替えられる
- [ ] Rich Presenceに振り返りの入力内容が一切含まれていない（プライバシー確認）
- [ ] （タイマー装飾のマルチプレイ共有機能は実装しない。Steam Rich Presenceによる状態表示は別物として実装する）
