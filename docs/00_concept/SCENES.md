## 画面遷移の関係図（概要）

```
タイトル画面
  └─ 拠点画面（ハブ）
       ├─ 冒険選択画面
       │    ├─ ストーリーステージ ─→ パーティ選択画面 ─→ 戦闘画面
       │    └─ トレーニングモード
       ├─ ギルド
       │    ├─ 倉庫
       │    ├─ ショップ
       │    ├─ 育成（キャラページ）
       │    ├─ 研究
       │    └─ 作業場
       ├─ ポモドーロ
       │    ├─ 加護選択 → 作業 → 振り返り → 休憩 → （次セット or 終了）
       │    ├─ 記録画面
       │    └─ タイマー装飾
       ├─ 設定
       └─ シナリオ
```
