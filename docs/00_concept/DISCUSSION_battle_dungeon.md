# 戦闘・周回の改良案（話し合いメモ）

**作成日：2026-08-22**

**位置づけ：** `GAME_DESIGN.md` の3章（戦闘）・4章（ステージ）を置き換えうる新方針の検討メモ。まだ決定事項ではなく、たたき台。

---

## 発端

現行は面（ステージ）で分けて周回するトリッカル型の戦闘システム。実装としては堅実だが、「わくわくが足りない」という課題感があった。特に**周回（同じ面を繰り返す部分）**で顕著。

---

## 検討した方向性（初期案・不採用〜保留）

固定面のまま周回に変化をつける案をいくつか出したが、後にダンジョン化の方向へ議論が進んだため保留：

- 敵編成のシャッフル（面ごとの敵プールから抽選）
- デイリーミューテーター（日替わりの特殊ルール）
- 周回ごとの小さいミニクエスト
- ウェーブ構成のランダム順
- エリート出現（低確率で強化された雑魚）

→ これらは**踏破済み領域の周回に変化を持たせる手段**として、後述の構造の中でなお有効な可能性がある。

---

## 決定した方向性：シナリオと難ダンジョンの分離

### 全体構造

```
シナリオ（導入・常設）
  ├─ 一本道の常設ダンジョンとして構成
  ├─ 定期的にボス → 突破でストーリー解放（章が開く）
  ├─ 序盤は短い間隔でボス、後半は間隔を伸ばす想定
  ├─ 素材はバランスよく落ちる（偏りなし。従来の「建築・経験値偏重」から変更）
  └─ 負けてもノーリスク・何度でもやり直し・周回可能

難ダンジョン（本命・別モード）
  ├─ 難易度別に複数本を並列で用意（章立てではなく難易度違いを複数種類）
  ├─ 週替わり通行証（使用期限あり）を消費して挑戦。スタミナは不要
  ├─ 一本道・撤退式。インベントリ枠が有限（拾いすぎたら選別が必要）
  │   └─ 枠は潜行中に追加購入で拡張可能
  ├─ 自分の意志で撤退 → その時点のインベントリの中身を確定で持ち帰る
  └─ 敗北 → 全ロスト（インベントリの中身が消える。通行証は挑戦時点で消費済み）

周回ステージ（従来の面制）
  └─ シナリオ・難ダンジョン以外の形としてどう残すかは未整理（要検討）
```

### 各モードの役割分担

| | シナリオ | 難ダンジョン |
|---|---|---|
| 進み方 | 一本道・チェックポイント式（何度でも戻れる） | 一本道・撤退式（インベントリ制） |
| 負けたとき | ノーリスク、やり直し可 | 全ロスト |
| 挑戦制限 | 制限なし | 週替わり通行証 |
| 報酬の傾向 | バランスよく | ハイリスクな分、質が良い |
| 節目 | 定期的にボス→ストーリー解放 | 深さがそのまま報酬に直結 |

## 難ダンジョンの中の3層構造

救済策の検討を経て、難ダンジョンへの挑戦手段は最終的に3種類に整理された（2番目は不採用）。

1. **通常挑戦（週替わり通行証）**
   - 一発勝負。全ロストのリスクあり。深く潜るほど報酬は大きい。

2. **~~10倍コース（強化状態で挑戦）~~ → 不採用**
   - 検討したが「無限リトライ可能な救済チケット」案に置き換えて不採用となった。

3. **救済チケット（採用）**
   - **無限リトライ可能**（通行証を消費せず、負けても何度でも再挑戦できる）
   - **イベント・分岐などの「上振れ要素」は与えない**（運や工夫による旨みを乗せる意味がないため）
   - 道中の固定的な戦利品は通常挑戦と同じ
   - **到達ボーナスの箱は少なめ**にし、通常挑戦との差別化を保つ
   - **ステータスが足りなければクリアは普通に不可能。** 実力を誤魔化す裏技ではなく、あくまで「詰んだ人の練習台・箱の下限確保」としての位置づけ
   - 目的：実力不足で本編に一切触れられない詰みを回避しつつ、難ダンジョンの到達深度が「実力の目安」として機能する性質は壊さない

## 設計原則との整合性チェック

既存の設計原則（`GAME_DESIGN.md` 1章）との関係：

- **「頑張ったら素直に嬉しい」**：シナリオは維持、難ダンジョンは緊張感を意図的に持たせる形に振り切った（原則からの意図的な逸脱）
- **「やって後悔したと思わせない」**：難ダンジョンの全ロストはこの原則と本来ぶつかるが、①撤退可能にする②救済チケットで詰みを回避する、の2点で後悔の質を「事故」から「判断ミス」に寄せている
- **「等級を上げると必ず何かが開く」「割り振りポイントは無料で振り直せる」＝詰みを作らない**：救済チケットはこの系譜の対応策

## 未決事項（次回以降）

- シナリオのボス間隔・章立ての具体的な数
- 難ダンジョンの難易度分けの基準（敵の強さだけか、報酬の質も変えるか）
- 難ダンジョンの階の進み方（一本道か、階ごとに軽い分岐を挟むか）
- 従来の「周回ステージ（面制）」の位置づけ（難ダンジョンの踏破済み領域に吸収するか、別枠として残すか）
- 救済チケットの入手経路（常時購入可能か、詰まった人への動的トリガー配布か）
- 救済チケットの箱の量（通常挑戦とどの程度の落差をつけるか）
- インベントリ枠の初期値・追加購入コストの数値
- 通行証の週あたりの枚数、使用期限の長さ
