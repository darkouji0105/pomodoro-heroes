# ダンジョン探索ローグライク 設計ドキュメント

## コンセプト

Trickcalライクなキャラ育成 × ダンジョン探索型ローグライク。
Chrono Arkに近いが、カード抽選ではなく「キャラを直接操作」する形式。
戦闘は自動、スキル発動のみ手動介入。

タルコフから「リスクと所有欲の刺激」を抽出し、ダンジョン設計のベースにしている。
（タルコフの重量テトリス的な煩雑さは意図的に採用しない）

---

## 設計の一貫原則

**「あらゆる安全・安心は、何かを犠牲にしないと手に入らない」**

すべてのシステムがこの一文に集約される。個別のギミックではなく、
一本の文法（＝有限リソースの再配分）で全システムが繋がっていることが本作の強み。

| 要素 | 得るもの | 犠牲にするもの |
|---|---|---|
| ポーションを使う | HP回復・MAX HP回復 | 持ち帰り価値（売却益） |
| ポーションを持ち歩く | 保険 | インベントリ枠（戦利品を諦める） |
| 回復スキルを選ぶ（6→2） | 戦闘終了時のHPを高く保つ | 攻撃/防御スキルの機会 |
| 枠拡張を買う | インベントリの余裕 | 他の強化アイテムを買う資源 |
| 深く潜る | より良い戦利品 | 撤退できる安全マージン |
| 弱ってるキャラを放置 | 他の行動の自由 | そのキャラが狙われ続けるリスク |

---

## ダンジョン構造

- **死亡ペナルティ**: アイテム全ロスト
- **撤退**: 決められた場所（フロアごとのお預けポイント）のみ可能
- **途中離脱**: 許可。ただし持ち帰れるのは一部のみ
  - インベントリが埋まっている状態で離脱する場合、何を残し何を捨てるかをプレイヤーが選択する
- **ショップ**: フロア最後に配置。そのランだけの一時通貨で、インベントリ拡張や強化アイテムを購入できる
  - 「枠を拡張するか、他の強化を買うか」の資源配分の駆け引きが発生する
  - 脱出自体に追加コストは課さない方向（案）。ただし要検証

---

## インベントリシステム

- **個数制限方式**（重量制ではない。タルコフの煩雑さを避けるための判断）
- 探索アイテムと戦利品は**同じ枠**に入り、競合する
- ポーション・宝箱の鍵・戦利品はすべて**一律1枠**（重み付けなし、公平でシンプルな設計）
- 初期枠数は少なめ。ショップやアイテムで拡張可能
  - 序盤: カツカツで判断がシビア → 緊張感が高い
  - 中盤以降: 拡張していくことで余裕が生まれる → 育成の実感に繋がる

## HP・回復システム

### 基本ルール

- **MAX HPは戦闘終了時のHPがそのまま新しいMAX HPになる**
  - 例: MAX HP100 → 戦闘中50まで削れて、終了時までに80まで戻せたなら、次のMAX HPは80
- MAX HP減少に下限は設けない（際限なく削れていく想定）
- **MAX HPを回復できるのはポーションのみ**

### 回復スキル（6→2枠から選択）とポーションの役割分担

| | 効くタイミング | 役割 |
|---|---|---|
| 回復スキル | 戦闘中 | 終了時のHPを少しでも高く着地させる（＝目減りを減らす、その場の技術介入） |
| ポーション | 戦闘後いつでも | 既に確定した目減り分を事後的に埋め戻す（資源管理の判断） |

この時間軸の分離により、「戦闘中回復を絞ると回復役が不要になる」という矛盾を回避している。
回復スキルには回復スキルにしかできない仕事（終了時の値を左右すること）がある。

### 回復量の設計方針

- 回復スキル・ポーションともに、HPの絶対量ではなく**割合**で設計する（インフレ対策）
- 回復スキル: 敵の平均攻撃力の1〜2発分程度が目安。「これさえあれば無敵」にならない強さに抑える
- ポーション: 枠を消費し持ち帰り価値も失うという代償が重いため、効果は強めでよい（大回復〜MAX HP回復級）

## 敵AI：弱者狙い行動

- 一部の敵・場面限定で「一番HPが減っているキャラを狙う」行動パターンを実装
- 常時ではなく、意図した緊張の山場としてのみ使用する（乱用すると負のスパイラルで詰みやすくなるため）
- 狙われることが予測できるよう、視覚的な予兆（ターゲット表示など）を用意する

### 注意点（要検証）
- 弱ってるキャラを見捨てる戦略が最適解になりうる → 意図した駆け引きかどうか要確認
- MAX HPが既に下がっているキャラは、狙われ続ける負のスパイラルに入りやすい
  → 意図どおりの緊張感として採用（「削れたキャラは危険が続く、だから早めにポーションで手当てすべき」という圧力）

## 参考にした知見

### Slay the Spire（実データ）
- 初回プレイ全体勝率: 約9.6%
- Ascension 0（無強化）: 初心者9%程度 → 熟練者は90%台まで到達
- StS2ではStS1より意図的に易化（初回9%→16%、最高難度3%→17%）
- **示唆**: 「相場」は初心者と熟練者で10倍以上ブレる。誰を基準にするかを先に決める必要がある

### Chrono Ark
- 回復ゲージ方式: ダメージは緑ゲージとして猶予扱いになり、戦闘終了時に全回復
- 瀕死システム: HP0以下でも即座に戦闘不能にならず、瀕死状態からプラスまで回復すれば復帰可能
- 回復がシビアな設計であることがプレイヤー間の共通認識
- **示唆**: カード抽選のランダム性を「猶予システム」で吸収する設計。自分のゲームは直接操作なので、猶予より「判断の重み」で緊張感を作る方が合っている

### Roguebook（開発者インタビュー）
- プレイヤーが失敗後に離脱する理由は「なぜ負けたか分からない」「不公平だと感じた」場合
- **示唆**: 死亡・撤退失敗の原因が明確にプレイヤーに伝わる仕組みが最重要。育成でどうにかなる設計はこのリスクを大きく下げられる

### タルコフ（反面教師）
- リスクと所有欲の刺激は強力だが、「見えない一発死」による理不尽さが欠点
- 重量テトリス管理は煩雑
- **示唆**: 所有欲・リスクの緊張感だけを抽出し、理不尽さと煩雑さは持ち込まない
